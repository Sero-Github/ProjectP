# ProjectP

화면 중앙의 **심장부(플레이어)** 를 지키기 위해 사방에서 몰려오는 적을 물리치고, 전리품으로 얻은 **블록을 가방에 채워 넣어** 강해지는 2D 디펜스 · 퍼즐 게임입니다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 디펜스, 시뮬레이션, 퍼즐 |
| 타겟 유저 | 캐주얼 퍼즐 게임 유저, 방치형 게임 유저 |
| 플랫폼 | Windows (차후 Mobile 확장 예정) |
| 유통 | Steam (예정) |
| 엔진 | Unity 6 (`6000.3.12f1`), URP 2D |
| 개발 단계 | 프로토타입 |

## 게임 소개

- **방치해도 즐거운 화면** — 폭죽을 바라보듯, 화려한 파티클이 흰 배경을 물감처럼 채워 가는 모습을 보는 것만으로도 지루하지 않은 게임을 지향합니다.
- **타워를 설치하지 않는 디펜스** — 플레이어는 직접 공격을 조작하지 않습니다. 가방에 어떤 블록을 배치하느냐에 따라 공격 방식과 속성 연계가 달라집니다.
- **블록 퍼즐로 성장** — 능력치를 가진 블록을 가방의 빈 칸에 채워 넣는 것이 곧 성장입니다. 어떤 블록을 주력으로, 어떤 블록을 임시로 쓸지 고민하는 것이 핵심 재미입니다.

## 핵심 시스템

### 🧱 블록
- 몬스터를 처치하면 드롭되며, 최대 3×3 영역 안에 최대 5칸으로 구성됩니다. 회전은 불가능합니다.
- **스탯 블록**은 체력·공격력·방어력·쿨타임 감소 등 스탯을, **스킬 블록**은 공격 스킬과 속성을 가집니다.
- 등급(★)이 있으며, 같은 블록끼리 **병합**해 강화할 수 있습니다.

### 📦 가방 · 창고
- 창고(인벤토리)에 보관된 블록을 가방 그리드에 겹치지 않게 배치하면 능력치가 적용됩니다.
- 전투 중에도 가방을 열어 배치를 바꿀 수 있습니다.

### ⚔️ 공격 스킬
| 스킬 | 설명 |
| --- | --- |
| 탄환 | 가장 가까운 적에게 자동 발사되는 직사각형 탄환. 관통력만큼 적을 관통 |
| 광역 탄환 | 소멸 지점에 원형 **공격 지대**를 생성해 지속 피해 |
| 지원 | 적에게 돌진했다 돌아오는 **지원 크리쳐**를 소환, 이동 궤적에 속성 흔적을 남김 |

스킬 블록을 배치하기 전에는 무속성 탄환을 기본으로 발사합니다.

### ⚡ 속성
적은 마지막으로 맞은 속성을 갖게 되며(**속성 주입**), 속성마다 고유한 효과가 발생합니다.

| 속성 | 효과 |
| --- | --- |
| 🔴 빨강 | 폭발 — 주입 즉시 주변 범위 피해 |
| 🟠 주황 | 강화 — 적이 가진 속성 효과를 한 번 더 발생 |
| 🟡 노랑 | 감전 — 지속 피해 + 공격 속도 감소 |
| 🟢 초록 | 둔화 |
| 🔵 파랑 | 방어력 하락 |
| 🟣 보라 | 독 (중첩) |
| ⚪ 회색 | 넉백 |

### 🏰 스테이지 · 라운드
- 1개 스테이지는 10라운드로 구성되며, 마지막 라운드는 보스 라운드입니다.
- 라운드마다 100초 동안, CSV에 정의된 몬스터가 비율에 맞춰 균등하게 소환됩니다.
- 승리 시 다음 라운드로, 사망 시 이전 라운드로 이동하며, 라운드 종료마다 자동 저장됩니다.

### 👿 몬스터
| 형태 | 역할 | 특징 |
| --- | --- | --- |
| 원형 | 기본 | 근접 |
| 삼각형 | 원거리 | 원거리 공격, 낮은 체력 |
| 사각형 | 탱커 | 높은 체력·방어력 |
| 오각형 | 보스 | 전반적으로 높은 스탯 |

몬스터 스탯은 현재 진행도(스테이지·라운드)에 비례해 강해집니다.

## 프로젝트 구조

```
ProjectP/
├── Game Design Documents/   # 기획 문서 (Obsidian 마크다운)
│   ├── PROJECT - P.md       # 게임 개요 · 핵심 가치
│   ├── 🚧 작업 예정.md       # 우선순위별 작업 예정 사항
│   ├── System/              # 시스템 기획 (블록, 가방, 스킬, 속성, 스탯, 스테이지, 몬스터)
│   └── UXUI/                # UI 로케일 자료
└── ProjectP/                # Unity 프로젝트
    └── Assets/
        ├── Data/            # ScriptableObject 설정, StageTable.csv
        ├── Prefabs/         # 블록, 탄환, 몬스터 프리팹
        ├── Scenes/          # Main(타이틀), Game(인게임), Test* (테스트 씬)
        └── Scripts/
            ├── Main/        # 타이틀 메뉴
            ├── Game/
            │   ├── Block/       # 블록 생성 · 드롭 · 스탯
            │   ├── Inventory/   # 가방 · 창고 그리드, 드래그 앤 드롭
            │   ├── Merge/       # 블록 병합
            │   ├── Skill/       # 탄환 · 광역 탄환 · 지원 크리쳐 · 속성
            │   ├── Stat/        # 스탯 정의 및 합산
            │   ├── Stage/       # 라운드 진행, 스테이지 CSV 파싱, 소환 순서
            │   ├── Unit/        # 플레이어 · 몬스터
            │   ├── Effect/      # 폭발 · 사망 파티클 연출
            │   ├── Save/        # JSON 저장 / 불러오기
            │   └── UI/          # 라운드 · 스킬 상태 표시, 일시정지 메뉴
            ├── Editor/      # 커스텀 인스펙터, 에디터 메뉴, EditMode 테스트
            └── Test/        # 테스트용 스크립트
```

## 시작하기

1. Unity Hub에서 **Unity `6000.3.12f1`** 을 설치합니다.
2. 저장소를 클론한 뒤 Unity Hub에서 `ProjectP/ProjectP` 폴더를 프로젝트로 엽니다.
3. `Assets/Scenes/Main.unity` 를 열고 Play 합니다. (빌드 순서: `Main` → `Game`)

### 조작
- 전투는 자동으로 진행됩니다. 블록은 마우스 드래그로 가방 · 창고 · 병합 슬롯에 배치합니다.
- `ESC` — 일시정지 메뉴

### 데이터 수정
- **스테이지 구성**: `Assets/Data/StageTable.csv` (`Stage, Round, Circle, Triangle, Square, Pentagon`)
- **밸런스 수치**: `Assets/Data/` 의 ScriptableObject 에셋 (탄환, 속성, 블록 스탯, 몬스터, 라운드 설정 등)

### 에디터 메뉴 (`ProjectP/`)
| 메뉴 | 기능 |
| --- | --- |
| `Save/Delete Save` | 저장 파일 삭제 |
| `Save/Open Save Folder` | 저장 폴더 열기 (`persistentDataPath/save.json`) |
| `Physics/Setup Layers` | 물리 레이어 설정 |
| `Font/Bake Static Atlases` | NotoSansKR 정적 폰트 아틀라스 생성 |
| `Font/Apply Default Font To Scenes` | 씬 텍스트에 기본 폰트 적용 |

### 테스트
`Window > General > Test Runner` 의 **EditMode** 탭에서 스테이지 소환 순서 테스트(`SpawnSequenceTests`)를 실행할 수 있습니다.

## 커밋 컨벤션

커밋 메시지는 `[분류] 내용` 형식을 따릅니다.

```
[스킬] 지원 크리쳐 구현
[스테이지] 라운드 진행과 자동 저장 구현
[기획] 오탈자 수정, 기획 우선 순위 문서 작성
```

## 기획 문서

상세 기획은 [`Game Design Documents/`](Game%20Design%20Documents/) 폴더에서 확인할 수 있습니다. [Obsidian](https://obsidian.md/)으로 열면 문서 간 링크와 이미지가 정상적으로 표시됩니다.
