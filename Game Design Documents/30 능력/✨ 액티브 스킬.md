# 2. 액티브 스킬 정의
- 액티브 스킬은 ==**액티브 블록**==을 가방에 배치하면 활성화되는 스킬입니다.
	- 액티브 블록은 [[🧱 블록]] 중 4칸, 5칸 블록입니다. → [[🧱 블록#2. 블록 정의]]
	- 액티브 블록은 스탯, 공격 스킬, 속성을 가지지 않고 액티브 스킬 하나만 가집니다.
- 활성화된 액티브 스킬은 쿨타임을 가집니다.
- 액티브 블록은 보스 처치 시에만 얻을 수 있습니다. → [[🏰 스테이지#2. 스테이지 구성]]
