# 1. 기획 의도
- 플레이어에게 블록은 다음 단계로 넘어가기 위한 열쇠로 인식되어야 합니다.
- 게임을 방치하여 많은 블록을 파밍하고, 파밍해둔 많은 블록 중 원하는 블록을 찾아 병합 또는 강화로 앞으로 나아가는 경험을 느껴야 합니다.
	- 플레이하며 원하는 블록을 수집하는데 어려움이 없도록 해야합니다.
# 2. 블록 정의
![[InGame/Images/Pasted image 20260915135852.png|434]]
- 모든 블록은 다음과 같은 공통 사항을 가집니다.
	- 회전이 불가능합니다.
	- 각 블록 별로 고유한 [[📊 스탯]]을 가집니다.
	- 최대 크기는 가로 3칸, 세로 3칸 내에 배치되며, 최대 5개의 칸으로 구성됩니다.
		- [[🧱 블록#참고. 블록 종류]] 내의 블록을 사용할 예정입니다.
	- 등급을 가지고 있으며 1성, 2성, 3성... 등으로 표현합니다.
	- 등급은 최대 병합 횟수에 영향을 주며, 1등급 별로 1회 병합할 수 있습니다.
	- 스탯은 블록의 등급과 칸 수에 따라 변동됩니다.
		- 이는 CSV 파일로 관리됩니다.
		- 스탯 번호, 블록 칸 수, 스탯 수치로 구성됩니다.
- 블록에 빈 공간이 있다면 항상 좌상단으로 정렬되어야 합니다.
- 블록은 **원본 블록**과 **병합 블록**으로 칭합니다.
	- **원본 블록**은 블록 병합을 하지 않은 최초의 드롭 상태인 블록입니다.
	- **병합 블록**은 블록 병합을 한 번 이상한 블록입니다. 이는 블록 병합으로 소모할 수 없습니다.

# 3. 블록 병합
- 블록 병합은 두 개의 블록을 합쳐 블록이 가진 고유 능력치를 강화하는 시스템입니다.
## 4-1. 블록 병합 조건
- 블록 병합은 등급이 서로 같아야 합니다.
- 블록 병합은 골드를 일정 소모하여야 합니다.
	- 골드 소모량은 다음과 같은 CSV 파일로 구성됩니다.
		- 블록 등급, 사용 골드로 구성됩니다.
- 잔여 블록 병합 횟수가 남아있어야 합니다.
## 4-2. 블록 병합 구성
- 블록 병합 시 좌측의 블록은 **병합할 블록**입니다.
	- **병합할 블록**은 우측의 블록의 효과를 받는 것으로 강화 됩니다.
- 블록 병합 시 우측의 블록은 **소모 블록**입니다.
	- **소모 블록**은 병합을 하지 않은 **원본 블록**만 등록할 수 있습니다.
## 4-3. 블록 병합 불가능 조건
- 블록 병합 시 두 개의 블록이 서로 인접하여 있지 않다면 병합이 불가능합니다.
- 서로 다른 코어를 가진 블록을 병합하는 것은 불가능합니다.
- 병합한 블록의 결과가 최대 크기가 가로 3칸, 세로 3칸 초과 시 병합이 불가능합니다.
## 4-4. 블록 병합 완료
- 블록 병합 시 병합된 두 블록의 능력치를 합산하여 얻습니다.
- 블록 병합 시 두 개의 블록을 합친 블록을 결과물로 얻습니다.
