# 1. 기획 의도
- 플레이어가 가진 [[🧱 블록]]을 고를 때에 우선 순위를 정할 수 있도록 도와주는 장치입니다.
- 또한, 블록을 배치한 결과로 전투 화면이 달라지는 경험을 얻어야 합니다.
# 2. 스킬 정의
- 스킬은 공격 스킬과 스킬 속성으로 나누어집니다.
- 공격 스킬은 **어떻게 적을 타격하는가**에 초점이 맞춰집니다.
- 속성 부여는 **타격한 적을 어떻게 대미지를 주는가**에 초점이 맞춰집니다.
# 3. 공격 스킬
- 하기에 기술될 공격 스킬 중 한 종류가 랜덤하게 [[🧱 블록]]에 부여됩니다.
# 4. 속성
- 속성은 [[🧱 블록]]의 색상에 영향을 미치며, 공격 스킬의 대미지 계산에 영향을 줍니다.
- 속성은 공격의 특성과, 몬스터의 약점에 따라 조정됩니다.
- 몬스터는 한 가지 속성에 대해 대미지를 입을 경우 해당 속성을 갖게 됩니다.
- 다른 속성의 공격을 받았을 때, 아래의 설명에서 언급이 없다면, 받은 피해의 색으로 변화하며 속성이 변경됩니다. 이를 ==**속성 주입**==이라고 합니다.
	- 단, 몬스터는 주황색 속성을 가질 수 없습니다.
## 4-1. 속성 종류
### 4-1-1. 빨강(불)
- 색상 코드는 <span class="red">FFDDDD</span> 코드를 사용합니다.
- 빨강색은 불 속성으로 사용합니다.
- 불 속성이 주입되면, 지속적으로 화상 대미지를 주며, 적의 공격력이 비교적 강화됩니다.
### 4-1-2. 주황(강화)
- 색상 코드는 <span class="orange">FFEEDD</span> 코드를 사용합니다.
- 주황색은 강화 속성으로 사용합니다.
- 피격된 적이 가진 속성에 대해 공격을 강화하여 추가 대미지를 줍니다.
	- 몬스터에게 속성을 주입하지 않습니다.
### 4-1-3. 노랑(전기)
 - 색상 코드는 <span class="yellow">FFFFC8</span> 코드를 사용합니다.
 - 노란색은 전기 속성으로 사용합니다.
 - 전기 속성이 주입되면, 감전 대미지를 주며, 적의 공격 속도가 비교적 약화됩니다.
### 4-1-4. 초록(풀)
- 색상 코드는 <span class="green">DDFFDD</span> 코드를 사용합니다.
- 초록색은 풀 속성으로 사용합니다.
- 풀 속성이 주입되면, 적의 공격력을 약화시킵니다. 풀 속성을 가진 상태로 다른 속성이 주입되면 아래와 같은 연계가 발동됩니다.
	- 풀 + 불 = 더 강한 화상 대미지를 입으며 불 속성이 주입됩니다.
	- 풀 + 전기 = 잠시 이동이 멈추며, 전기 속성이 주입됩니다.
	- 풀 + 물 = 광역 물 속성 지대를 생성합니다. 물 속성이 주입됩니다.
		- 늪 지대를 생성하는 것을 의도하였습니다.
	- 풀 + 독 = 광역 독 속성 지대를 생성합니다. 독 속성이 주입됩니다.
		- 독 식물이 생성되는 것을 의도하였습니다.
	- 풀 + 바람 = 적이 더 크게 넉백됩니다. 바람 속성이 주입됩니다.
### 4-1-5. 파랑(물)
- 색상 코드는 <span class="blue">DDF6FF</span> 코드를 사용합니다.
- 파란색은 물 속성으로 사용합니다.
- 물 속성이 주입되면, 적의 이동 속도를 둔화합니다.
### 4-1-6. 보라(독)
- 색상 코드는 <span class="purple">DDDDFF</span> 코드를 사용합니다.
- 보라색은 독 속성으로 사용합니다.
- 독 속성이 주입되면, 지속적으로 독 대미지를 줍니다.
### 4-1-7. 회색(바람)
- 색상 코드는 <span class="gray">DEDEDE</span> 코드를 사용합니다.
- 회색은 바람 속성으로 사용합니다.
- 바람 속성이 주입되면, 적이 넉백됩니다.
	- 바람 속성이 2번 주입된 상태로 다른 속성이 주입되면, 해당 속성 지대를 생성하며, 해당 속성이 주입됩니다.
