# 1. 기획 의도
- 플레이어가 가진 [[🧱 블록]]을 고를 때에 우선 순위를 정할 수 있도록 도와주는 장치입니다.
- 또한, 블록을 배치한 결과로 전투 화면이 달라지는 경험을 얻어야 합니다.
# 2. 스킬 정의
- 스킬은 공격 스킬과 스킬 속성으로 나누어집니다.
- 공격 스킬은 **어떻게 적을 타격하는가**에 초점이 맞춰집니다.
- 속성 부여는 **타격한 적을 어떻게 대미지를 주는가**에 초점이 맞춰집니다.
# 3. 공격 스킬
- 하기에 기술될 공격 스킬 중 한 종류가 랜덤하게 [[🧱 블록]]에 부여됩니다.
- 모든 공격 스킬은 하기 [[⚔️ 스킬#4. 속성]]이 부여되며 모든 색과 부가 효과는 속성에 따라 부여됩니다.
- 모든 공격이 화면 밖으로 벗어나면, 삭제되어야 합니다.
## 3-1. 탄환
### 모티브
- 매직 서바이벌의 마력탄을 모티브로 구상하였습니다.
- 외형도 이와 동일합니다.
## 상세
- ==탄환==은 직사각형의 속성을 가진 탄환을 플레이어에서 가장 가까운 몬스터에게 자동 사출됩니다.
- 탄환이 사출될 때 쿨타임이 흐릅니다.
- 관통력을 N가질 때 마다 N번의 적을 관통할 수 있습니다.
### Scriptable Object
- 재사용 대기 시간(float)
- 이동 속도(float)
- 관통력(int)
## 3-2. 광역 탄환
### 상세
- ==광역 탄환==은 탄환과 외형은 같지만, 소멸 시 원형의 ==공격 지대==를 생성합니다.
- 광역 탄환은 사출될 때 쿨타임이 흐릅니다.
- 공격 지대가 생성되면, 유지 시간이 흐릅니다.
- 공격 지대가 생성될 때 작은 원형이 점점 커지면서 생성됩니다.
- 공격 지대 유지 시간이 지나면 소멸되며, 작아지면서 소멸됩니다.
### Scriptable Object
- 재사용 대기 시간(float)
- 공격 지대 유지 시간(float)
- 이동 속도(float)
- 공격 지대 지름(float)
## 3-3. 지형
### 모티브
- 지형은 리그 오브 레전드 - 트런들 E를 모티브로 구상하였습니다.
### 상세
- ==지형==은 쿨타임과 유지 시간을 가집니다. 
	- 쿨타임은 지형이 생성되었을 때 흘러갑니다.
	- 유지 시간은 최초 생성 시 시간이 흘러갑니다.
- 지형은 생성될 때 작은 원형이 점점 커지면서 생성됩니다.
- 지형 유지 시간이 지나면 소멸되며, 작아지면서 소멸됩니다.
- 지형은 중심점을 기준으로 원형의 공격 범위를 가집니다.
- 지형은 화면의 랜덤한 위치에 생성 되며, 공격 범위를 포함하여 화면 밖을 나갈 수 없습니다.
- 지형은 몬스터와 같이, 임의 공격 피격 시 다른 속성이 주입 될 수 있습니다.
- 지형은 몬스터와 충돌할 수 없으며, 몬스터는 지형을 피해서 이동해야 합니다.
### Scriptable Object
- 재사용 대기 시간(float)
- 지형 유지 시간(float)
- 지형 크기 지름(float)
- 범위 크기 지름(float)
## 3-4. 지원
### 모티브
- 지원은 다음을 모티브로 구상하였습니다.
	- 스타크래프트 - 캐리어, 인터셉터
	- 리그 오브 레전드 - 신지드 Q
### 생애 주기
- 플레이어를 지원하는 작은 원형 크리쳐를 ==지원 크리쳐==라 합니다.
- 지원 크리쳐는 스탯에 따라 생성합니다.
- 지원 크리쳐는 자체적으로 쿨타임을 가지며, 다음과 같은 행동을 반복합니다.
	- 1. 가까운 적 탐색 및 이동
	- 2. 이동 완료 후 배회
		- 배회는 다음과 같이 진행합니다.
		- 1. 이동한 적의 8방향 끝을 계산합니다.
		- 2. 이 중 3점을 랜덤으로 3방향을 선택 후 이 값의 -2 ~ 2 수치를 랜덤으로 구하여 값을 더합니다.
		- 3. 여기서 얻은 좌표 3곳을 배회합니다.
	- 3. 배회 완료 후 플레이어에게 이동
	- 4. 쿨타임 대기
- 지원 크리쳐가 이동한 궤적은 색 속성을 가지고, 에어브러시와 같은 효과를 흩뿌립니다.
### Scriptable Object
- 재사용 대기 시간(float)
- 이동 속도(float)
- 궤적 유지 시간(float)
# 4. 속성
- 속성은 [[🧱 블록]]의 색상에 영향을 미치며, 공격 스킬의 대미지 계산에 영향을 줍니다.
- 속성은 공격의 특성과, 몬스터의 약점에 따라 조정됩니다.
- 몬스터는 한 가지 속성에 대해 대미지를 입을 경우 해당 속성을 갖게 됩니다.
- 다른 속성의 공격을 받았을 때, 아래의 설명에서 언급이 없다면, 받은 피해의 색으로 변화하며 속성이 변경됩니다. 이를 ==**속성 주입**==이라고 합니다.
	- 단, 몬스터는 주황색 속성을 가질 수 없습니다.
## 4-1. 속성 종류
### 4-1-1. 빨강(폭발)
- 색상 코드는 <span class="red">FFDDDD</span> 코드를 사용합니다.
- 빨간색은 불 또는 폭발 속성으로 사용합니다.
- 빨간색 속성이 주입되는 즉시 폭발이 발생하며 주변 몬스터에게 대미지를 줍니다.
	- 폭발 대미지로 피격된 몬스터는 불 속성이 주입되지 않으며, 지속 피해를 주지 않습니다.
### 4-1-2. 주황(강화)
- 색상 코드는 <span class="orange">FFEEDD</span> 코드를 사용합니다.
- 주황색은 강화 속성으로 사용합니다.
- 피격된 적이 가진 속성에 대해 공격을 강화하여 추가 대미지를 줍니다.
	- 몬스터에게 속성을 주입하지 않습니다.
### 4-1-3. 노랑(감전)
 - 색상 코드는 <span class="yellow">FFFFC8</span> 코드를 사용합니다.
 - 노란색은 전기 속성으로 사용합니다.
 - 노란색 속성이 주입되면, 감전 대미지를 주며, 적의 공격 속도가 비교적 약화됩니다.
### 4-1-4. 초록(둔화)
- 색상 코드는 <span class="green">DDFFDD</span> 코드를 사용합니다.
- 초록색은 풀, 둔화, 점액 속성으로 사용합니다.
- 초록색 속성이 주입되면, 적의 이동 속도를 둔화합니다.
### 4-1-5. 파랑(방어력 하락)
- 색상 코드는 <span class="blue">DDF6FF</span> 코드를 사용합니다.
- 파란색은 물, 방어력 하락 속성으로 사용합니다.
- 파란색 속성이 주입되면, 방어력이 하락합니다.
	- 방어력 하락 순서는 스탯에 해당하는 값을 먼저 계산 후, 속성 값을 계산합니다.
### 4-1-6. 보라(독)
- 색상 코드는 <span class="purple">DDDDFF</span> 코드를 사용합니다.
- 보라색은 독 속성으로 사용합니다.
- 보라색 속성이 주입되면, 지속적으로 독 대미지를 줍니다.
### 4-1-7. 회색(넉백)
- 색상 코드는 <span class="gray">DEDEDE</span> 코드를 사용합니다.
- 회색은 바람 속성으로 사용합니다.
- 회색 속성이 주입되면, 적이 넉백됩니다.
	- 바람 속성이 2번 주입된 상태로 다른 속성이 주입되면, 해당 속성 지대를 생성하며, 해당 속성이 주입됩니다.
