# 1. 기획 의도
- 플레이어에게 가방은 열쇠로 풀 수 있는 자물쇠로 인식되어야 합니다.
	- 자물쇠라는 뜻은 다음과 같습니다.
		- 열쇠가 있어도 열쇠 구멍이 어디있는지 찾지 못하면 풀 수 없습니다. 이는 문제를 인식하였으나 문제를 해결 불가능한 것을 뜻합니다.
		- 다수의 와이어락으로 잠겨져 있다면 순차적으로 풀어야 한다는 의미입니다. 이는 문제를 인식하였으나 순서와 한계점이 있어, 한 번에 해결이 불가능한 것을 뜻합니다.
# 2. 가방 정의
- [[🧱 블록]]을 배치하여 능력치를 얻을 수 있는 공간 하나를 가방이라고 합니다.
- 가방은 레벨을 가지며 다음과 같은 기능을 지닙니다.
	- 가방 레벨을 올리기 위해서는 가방에 배치된 코어의 합산 레벨이 일정 달성되어야 하며, 골드를 소모해야 합니다.
	- 가방 레벨이 오르며 가로, 세로 최대 칸 수가 증가되거나, 가방 개수가 늘어날 수 있습니다.
- 하나의 가방에 정해진 [[📊 스탯]]이 배치되어 있다면 시너지 효과를 얻을 수 있습니다.
	- 시너지 효과는 추후 작성 예정
- 가방의 정보는 CSV 파일로 관리되며 구성은 다음과 같습니다.
	- 가방 레벨, 코어 합산 레벨, 가방1 가로, 가방1 세로, 가방2 가로, 가방2 세로, ...
	- 가방의 제한 개수를 정해 놓지 않아 열이 더 늘어날 수 있습니다.
	- 가방이 존재하지 않는다면 0으로 저장됩니다.
