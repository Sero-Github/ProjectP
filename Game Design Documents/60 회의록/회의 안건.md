# 회의 안건
- 다음 회의에서 논의할 안건을 모아 둔 문서입니다.
- 회의일: 미정
- 안건이 결정되면 결과를 해당 회의록에 적고, 이 문서에서는 결정된 회의록으로 링크합니다.

# 1. 탄환 개수 증가 보너스
- **결정할 질문**: 탄환 점수 보너스 중 "해당 속성 탄환 개수 증가 1개"를 유지할까요?
- **현재 상태**
	- [[📊 스탯#4-1. 탄환]]: 10점마다 보너스 3개(속성 공격력 증가 10, 탄환 스킬 쿨타임 감소 5%, 해당 속성 탄환 개수 증가 1개)를 순서대로 반복해서 부여합니다.
	- [[2026-11-18#5-1. 안건 외 결정 사항]]: 가방에 넣은 블록 하나당 탄환은 한 개입니다(A). [[⚔️ 스킬#3-1. 탄환]]에도 같은 내용이 반영되어 있습니다.
	- 보너스가 탄환 개수를 늘리면 "블록 하나당 탄환 하나"와 충돌합니다.
- **선택지**
	- 보너스 삭제: 보너스 순환을 나머지 두 항목으로 줄입니다.
	- 보너스 유지: 블록당 탄환 1개는 기본값이고, 점수 보너스로 그 블록의 탄환이 늘어난다고 명시합니다.
	- 다른 보너스로 교체: 탄환 개수 대신 다른 보너스를 넣습니다.

# 2. 다른 스탯끼리 스탯 블록 병합
- **결정할 질문**: 스탯이 서로 다른 스탯 블록끼리도 병합할 수 있게 할까요?
- **현재 상태**
	- [[🧱 블록 병합#3. 블록 병합 조건]]: 스탯 블록은 같은 스탯을 가진 블록끼리만 병합할 수 있습니다.
	- 스킬 블록은 2026-11-19 결정으로 속성(색상)만 같으면 스킬이 달라도 병합할 수 있고, 결과는 메인 블록(병합할 블록)의 것을 유지합니다.
	- [[🚧 작업 예정#생각 중]]에 "스탯 블록은 서로 합쳐도 문제 없지 않나?"라는 메모가 남아 있습니다.
- **선택지**
	- 같은 스탯끼리만 (현재 유지)
	- 다른 스탯끼리도 허용: 스킬 블록처럼 결과는 메인 블록의 스탯을 유지합니다.
