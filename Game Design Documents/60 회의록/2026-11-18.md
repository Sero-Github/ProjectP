# ProjectP 미정 사항 회의 안건
- 회의일: 2026-11-18
- 기획 문서와 현재 구현을 대조해 나온 미정 사항 18건입니다.
- 종류별로 묶었고, 안건마다 우선순위를 별 1~5개로 표시했습니다. 별 5개는 정해지지 않으면 구현을 시작할 수 없는 안건입니다.
- 기획으로 이미 정해져 구현만 남은 사항은 제외했습니다.

# 5. 회의 결과 (2026-11-18)
- #1 병합 횟수와 등급
	- 모든 블록의 병합 가능 횟수는 3회입니다. 병합 횟수를 모두 쓴 블록만 강화할 수 있고, 1강마다 강화 전 원본 점수의 20%가 더해집니다(원본 100 → 1강 120, 2강 140). B 기록에는 5강이 최대(원본 100 → 200)로 적혀 있습니다.
	- 표기: 병합 횟수는 "합", 강화 수치는 "강"으로 부릅니다. 병합을 다 쓰고 강화를 2회 한 블록은 "3합 2강"으로 표시합니다. 등급·n성·돌파는 명칭 후보였고 쓰지 않습니다.
- #2 큐브 획득량
	- 큐브는 블록 분해로만 얻습니다. 인벤토리가 가득 찬 뒤 드롭되는 블록은 자동으로 분해됩니다. 분해 보상량과 병합 비용의 균형은 논의되지 않았습니다.
- #3 큐브 소모처
	- 가방 추가(가방 개수), 가방 크기 확장(레벨업), 블록 병합, 인벤토리 확장에 씁니다.
- #4 블록 드롭 로직
	- 스테이지를 클리어할 때마다 속성·스킬 블록이 순서대로 해금되고, 해금된 블록은 이후 어느 스테이지에서나 드롭됩니다.
	- 예: 1스테이지는 스탯 블록만 나오고 보스를 잡은 뒤 빨간 속성이 추가됩니다(A). 10스테이지를 끝내 초록 속성이 해금되면 1스테이지에서도 초록 블록이 나올 수 있습니다(B).
- #5 스탯 블록과 스킬 블록 비율
	- 일단 해금된 종류끼리 균등 확률로 둡니다.
- #6 회복 아이템
	- 회복 아이템은 액티브 스킬로 바뀝니다. 액티브 스킬은 회복과 폭탄이며, 액티브 블록을 가방에 배치하면 활성화되고 쿨타임을 가집니다. 액티브 블록을 분해하려 하면 경고를 표시합니다.
- #7 보스 최초 처치 보상
	- 액티브 블록은 보스 처치 시에만 얻고, 일반 몬스터에게서는 드롭되지 않습니다.
- #8 4칸·5칸 블록 도입 시점
	- 4칸·5칸 블록은 액티브 스킬 전용입니다. 1~3칸 블록은 지금처럼 스탯·스킬·속성을 가집니다.
- #9 스킬 블록의 점수
	- 블록 한 칸당 5점이고, 병합하면 소모된 블록의 점수를 그대로 더합니다. 블록 점수 상세 내용은 문서로 작성하기로 했습니다.
- #10 타격 우선순위
	- 가까운 적, 멀리 있는 적, 체력 높은 적 세 가지입니다. 스킬 블록의 옵션으로 드롭 시 정해지며, 플레이어가 바꿀 수 없습니다.
- #11 몬스터 이동 방식
	- 몬스터의 원거리 공격은 없앱니다.
	- 원형은 플레이어를 향해 직선 이동하고, 삼각형은 직선으로 오다가 간헐적으로 대각선으로 일정 거리를 이동한 뒤 다시 직선으로 옵니다. 사각형은 주변에 범위 버프(이동 속도 또는 방어력)를 겁니다(B). 오각형은 정해지지 않았습니다.
- #12 회색 속성 추가 사양
	- 사양을 삭제합니다.
- #13 미정 수치
	- 대미지 배율 표를 만들고, 대미지 계수는 CSV 파일로 작성합니다(B). 쿨타임 감소 상한, 지원 크리쳐 수치, 빨강 폭발 범위는 따로 논의되지 않았습니다.
- #14 가방 크기
	- 기본 크기는 3×3이고, 업그레이드는 CSV 한 줄로 이어지는 단계로 관리합니다.
	- CSV 열은 레벨, 필요한 큐브, 가방 1 가로·세로, 가방 2 가로·세로 순입니다.
	- 예시: 레벨 1 → 0큐브, 가방 1 3×3 / 레벨 2 → 100큐브, 3×4 / 레벨 3 → 300큐브, 4×4 / 레벨 4 → 1000큐브, 가방 1 4×4 + 가방 2 3×3 새로 생성.
- #15 가방 레벨·여러 가방(탭)·시너지
	- 가방 레벨업과 가방 추가는 #14의 CSV를 따르고 큐브를 씁니다. 시너지는 추가할 계획이 없어 제외합니다.
- #16 인벤토리
	- 기본 50칸이고 확장할 때마다 50칸씩 늘어납니다. 가득 찬 뒤의 드롭은 자동 분해됩니다(#2).
- #17 블록 외형
	- 논의되지 않음.
- #18 정사각형 해상도
	- 정사각형 전환을 취소하고 1920×1080 기준으로 확정합니다.

## 5-1. 안건 외 결정 사항
- 가방 배치 제한: 스킬과 속성이 모두 같은 블록은 모든 가방을 통틀어 하나만 넣을 수 있습니다. 타격 옵션이 달라도 넣을 수 없습니다.
- 가방에 넣은 블록 하나당 탄환은 한 개입니다(A).
- 블록 병합은 같은 속성·같은 스킬의 블록끼리만 가능하고, 병합된 블록은 재료로 쓸 수 없습니다(A).
- 블록 강화(합·강 표기)와 액티브 스킬은 새 시스템이라 기획 문서를 새로 작성해야 합니다.
