# 1. 기획 의도
- [[👿 몬스터]]가 발생하는 각 스테이지를 서술한 문서입니다.
# 2. 스테이지 구성
- 한 스테이지의 구성은 라운드의 모음입니다. 앞자리 숫자는 스테이지, 뒷자리 숫자는 라운드로 출력합니다.
	- Ex) 100 - 1
- 각 스테이지의 마지막 라운드는 보스 라운드로 구성되며 해당 라운드의 보스를 최초로 처치 시 추가 보상을 얻습니다.
	- 각 스테이지 마지막 라운드는 10라운드로 결정합니다.
	- 보스 처치 보상은 [[✨ 액티브 스킬|액티브 블록]]입니다.
	- 액티브 블록은 보스 처치 시에만 얻을 수 있으며, 일반 몬스터에게서는 드롭되지 않습니다.
	- 보스를 처치하여 스테이지를 클리어하면 새로운 블록이 해금됩니다. 자세한 내용은 [[#6. 블록 해금]]을 따릅니다.
- 각 스테이지의 몬스터 구성은 CSV 파일로 관리하며 구성은 다음과 같습니다.
	- 스테이지, 라운드, 원형 몬스터 개수, 삼각형 몬스터 개수, 사각형 몬스터 개수, 오각형 몬스터 개수
	- CSV 목록은 [[📑 데이터 테이블]]에 정리되어 있습니다.
- 스테이지의 배경은 흰색으로 구성되어야 합니다.
- 하나의 라운드에서 승리 또는 패배의 결과로 라운드가 종료되면 게임은 자동으로 저장되어야 합니다.

# 3. 몬스터 생성 규칙
- 몬스터는 다음과 같은 값을 기준으로 몬스터를 생성합니다.
- 하나의 라운드에는 라운드 생성 시간 동안 몬스터가 생성되어야 하며, CSV 파일에 적힌 몬스터가 모두 그 시간 안에 소환되어야 합니다.
	- 라운드 생성 시간은 [[📊 몬스터 스탯#2. 공유 스탯]]을 따릅니다. 아래 예시는 100초 기준입니다.
	- 100초 안에 100개가 소환되어야 한다면, 1초에 1개가 소환되어야 합니다.
	- 100초 안에 200개가 소환되어야 한다면, 0.5초에 1개가 소환되어야 합니다.
	- 초 단위로 생성하지 않고 라운드 생성 시간을 N으로 나눈 기준으로 생성합니다.
- 몬스터 생성 순서는 일정한 규칙에 따라 비율을 맞추어 생성되어야 합니다.
	- 원형 몬스터가 100개, 삼각형 몬스터가 20개 일때, 원형 몬스터가 20개 소환될 때 삼각형 몬스터가 1개 소환되어야 합니다.
	- 비율이 소수점으로 내려가는 경우 소수점은 버림 처리 합니다.
	- 모든 비율은 몬스터가 가장 많은 기준으로 하며, 이는 원형 몬스터가 가장 많은 비율이 될수도, 아닐수도 있습니다.
	- 가장 많은 몬스터가 동률일 경우, 순서는 원형, 삼각형, 사각형, 오각형 순서로 소환되어야 합니다.
	- 오각형 몬스터의 경우 하나만 남았을 때, 반드시 마지막에 생성되어야 합니다.
# 4. 라운드 승리 시 처리
- 모든 적을 처치하고, 플레이어의 체력이 남아 생존해 있는 경우 승리 처리합니다.
- 라운드 승리 시 자동으로 다음 라운드로 이동하여야 합니다.
	- 다음 라운드가 없을 경우 다음 스테이지의 1라운드로 이동합니다.
# 5. 플레이어 사망 처리
- 플레이어가 사망하였을 때, 현재 이전 라운드로 돌아가 진행합니다.
	- 이전 라운드가 없는 경우 이전 스테이지의 마지막 라운드로 이동합니다.
- 플레이어가 사망 시 몬스터가 모두 죽는 파티클이 발생합니다.
# 6. 블록 해금
- 스테이지를 클리어할 때마다 속성과 공격 스킬이 각각의 순서에 따라 해금됩니다.
	- 속성과 [[⚔️ 스킬#3. 공격 스킬|공격 스킬]]은 서로 다른 해금 순서표를 따릅니다.
	- 1스테이지에서는 [[🧱 블록#2. 블록 정의|스탯 블록]]만 드롭됩니다.
	- 1스테이지 보스를 처치하면 빨강 속성이 해금됩니다.
- 스킬 블록은 속성과 공격 스킬이 모두 해금된 조합만 드롭됩니다.
- 해금된 속성과 공격 스킬은 이후 어느 스테이지에서나 드롭됩니다.
	- 10스테이지를 클리어하여 초록 속성이 해금되면, 1스테이지에서도 초록 속성의 스킬 블록이 드롭될 수 있습니다.
- 드롭 확률은 [[🧱 블록#5. 블록 드롭 로직]]을 따릅니다.
