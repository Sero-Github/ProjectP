# 1. 기획 의도
- 게임 초반, 블록을 얻으며 인벤토리가 가득 차 손해를 보는 감정을 느끼지 않기 위해 지속적으로 모니터링 하도록 합니다.
- 게임이 점차 진행되며 큐브의 사용 소모처로서 동작합니다.
# 2. 인벤토리 정의
- 인벤토리는 [[👿 몬스터]]를 처치 후 얻은 [[🧱 블록]]을 저장하는 공간입니다.
- 블록은 50개를 저장할 수 있습니다.
- 인벤토리는 확장이 가능하며 1번 확장 시 50칸이 추가됩니다.
	- 가방 확장 재료는 [[💎 큐브]]가 사용되며 이는 CSV로 관리됩니다. ^9cz4
		- 가방 확장 횟수, 필요 큐브
		- Ex) 1, 90
- [[🧱 블록#^gdzp|인벤토리가 가득 찬 상태라면 블록은 자동으로 분해됩니다.]]
# 3. UI/UX
- 인벤토리는 공통 사항으로 출력하는 공통의 UI로서 동작해야합니다.
	- [[📦 가방]], [[🧱 블록 병합]], [[🧱 블록 강화]], [[🧱 블록 분해]] 시에도 항상 출력되어야 합니다. 따라서 다른 UI를 출력할 빈 공간이 남겨져 있어야 합니다.
- 뒤로가기 버튼을 눌러 전투 화면으로 다시 돌아갈 수 있어야 합니다.
- 인벤토리는 4줄로 구성되어야 합니다.
- 인벤토리에 가진 블록 개수와 최대 인벤토리 개수가 출력되어야 합니다.
- 인벤토리 확장 버튼이 필요합니다.
	- **UI_INVENTORY_EXTENSION "인벤토리 확대"** 가 출력되어야 합니다.
	- 확장에 필요한 큐브 개수도 출력되어야 합니다.
