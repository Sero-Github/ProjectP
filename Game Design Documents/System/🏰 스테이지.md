# 1. 문서 개요
- [[👿 몬스터]]가 발생하는 각 스테이지를 서술한 문서입니다.
# 2. 스테이지 구성
- 한 스테이지의 구성은 라운드의 모음입니다. 앞자리 숫자는 스테이지, 뒷자리 숫자는 라운드로 출력합니다.
	- Ex) 100 - 1
- 각 스테이지의 마지막 라운드는 보스 라운드로 구성되며 해당 라운드의 보스를 최초로 처치 시 추가 보상을 얻습니다.
	- 각 스테이지 마지막 라운드는 10라운드로 결정합니다.
- 각 스테이지의 몬스터 구성은 CSV 파일로 관리하며 구성은 다음과 같습니다.
	- 스테이지, 라운드, 원형 적 개수, 삼각형 적 개수, 사각형 적 개수, 오각형 적 개수
# 3. 몬스터 생성 규칙
- 몬스터는 다음과 같은 값을 기준으로 몬스터를 생성합니다.
- 하나의 라운드에는 100초간 몬스터가 생성되어야 하며, CSV 파일에 적힌 몬스터가 모두 그 시간 안에 소환되어야 합니다.
	- 100초 안에 100개가 소환되어야 한다면, 1초에 1개가 소환되어야 합니다.
	- 100초 안에 200개가 소환되어야 한다면, 0.5초에 1개가 소환되어야 합니다.
	- 초 단위로 생성하지 않고 100초를 N으로 나눈 기준으로 생성합니다.
- 몬스터 생성 순서는 일정한 규칙에 따라 비율을 맞추어 생성되어야 합니다.
	- 원형 적이 100개, 삼각형 적이 20개 일때, 원형 적이 20개 소환될 때 삼각형 적이 1개 소환되어야 합니다.
	- 비율이 소수점으로 내려가는 경우 소수점은 버림 처리 합니다.
	- 모든 비율은 적이 가장 많은 기준으로 하며, 이는 원형 적이 가장 많은 비율이 될수도, 아닐수도 있습니다.
	- 가장 많은 적이 동률일 경우, 순서는 원형, 삼각형, 사각형, 오각형 순서로 소환되어야 합니다.
	- 오각형 적의 경우 하나만 남았을 때, 반드시 마지막에 생성되어야 합니다.
# 4. 라운드 승리 시 처리
- 모든 적을 처치하고, 플레이어의 체력이 남아 생존해 있는 경우 승리 처리합니다.
- 라운드 승리 시 자동으로 다음 라운드로 이동하여야 합니다.
# 5. 플레이어 사망 처리
- 플레이어가 사망하였을 때, 현재 이전 라운드로 돌아가 진행합니다.
