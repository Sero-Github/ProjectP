# 1. 문서 개요
- 게임 플레이 시 플레이어의 판단에 따라 유동적으로 변할 수 있는 스탯 값을 모아두었습니다.
# 2. 플레이어 스탯
## 2-1. HP
>[!INFO] HP 수식
> **HP = 100 + X**
- 플레이어 체력으로 고정 값으로 체력이 증가합니다.
- 플레이어 체력은 기본 값으로 100을 가집니다.

## 2-2. 회복 증가
> [!INFO] 회복 증가 수식
> **체력 회복량 = 회복 아이템 \* (1 + X \* 0.01)**
- 플레이어 체력 회복은 스텟은 %단위로 증가하며 ==**플레이어의 체력이 회복되었을 때 영향**==을 받습니다.
## 2-3. 방어력
>[!INFO] 방어력 수식
> **적용 대미지 = 대미지 - 방어력**
- 방어력은 플레이어에 받을 피해를 감소합니다.
- 최대 값은 제한이 없으며 실제 적용될 대미지를 고정 값으로 줄입니다.

## 2-4. 방어력 (% 적용) 

> [!WARNING] 실제 적용되지 않을 스탯입니다.
> 상기 방어력 스탯이 고정 값이 아닌 % 적용으로 변경 시 사용 될 스팩입니다.

>[!INFO] 방어력 수식
> **실제 적용 대미지 = 대미지 \* (1 - (X / (500 + X)))**
- 방어력은 플레이어에 받을 피해를 감소합니다.
- 최대 값은 500이며 50%까지 감소가 가능합니다.

## 2-5. 아이템 드롭 확률 증가
- ==**아이템 드롭 확률 개정 후 작성 예정**==

# 3. 스킬 스탯
- 플레이어 측의 공격에 적용되는 모든 스탯입니다.
## 3-1. 공격력
- 공격력은 모든 공격에 고정 값으로 증가합니다.
## 3-2. 쿨타임 감소
>[!INFO] 쿨타임 감소 수식
> **실제 스킬 쿨타임 = 스킬 쿨타임 \* (X / (100 + 1.05 \* X))**
- 수치를 위 수식에 대입하여 쿨타임 감소를 % 단위로 적용합니다.
- 최대 스탯 값은 500이며, 최대치로 적용 시 80%까지 감소가 가능합니다.

## 3-3. 스킬 지속 시간 증가
>[!INFO] 스킬 지속 시간 증가 수식
> **실제 스킬 지속 시간 = 스킬 지속 시간 \* (1 + X \* 0.005)**
- 스킬 지속 시간 증가 스탯에 따라 스킬의 지속 시간이 증가합니다.
- 최대 스탯 값은 500이며, 실제 적용 값은 250% 까지 증가할 수 있습니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
## 3-4. 스킬 범위 증가
>[!INFO] 스킬 범위 증가 수식
> **실제 스킬 범위 = 스킬 범위 + X × 0.005**
- 스킬 범위 증가 스탯에 따라 스킬 범위가 증가합니다.
- 최대 스탯 값은 500이며, 실제 적용 값은 250% 까지 증가할 수 있습니다.
- 스킬 범위가 증가하면 해당 퍼센트에 따라 이미지 크기가 리사이징되어야 합니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
## 3-5. 디버프 시간 증가
>[!INFO] 디버프 시간 증가 수식
> **실제 디버프 적용 시간 = 디버프 적용 시간 \* (1800 \* X) / (1000 + 7 \* X)**
- 디버프 시간 증가는 수식에 따라 스킬 디버프 시간이 증가합니다.
- 최대 스탯 값은 500이며, 실제 적용 값은 200% 까지 증가할 수 있습니다.
- 200 스탯을 가지고 있을 경우 150%가 적용됩니다.
- 500 스탯을 가지고 있을 경우 200%가 적용됩니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.

## 3-6. 디버프 중첩
- 디버프 중첩 스탯은 1당 1씩 중첩되며 최대 4 스탯까지 얻을 수 있습니다.
	- 디버프 중첩 스탯이 0이면, 디버프 최대 중첩은 1이 됩니다. (기본 적용 값)
	- 디버프 중첩 스탯이 1이면, 디버프 최대 중첩은 2가 됩니다.
	- 디버프 중첩 스탯이 4이면, 디버프 최대 중첩은 5가 됩니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
