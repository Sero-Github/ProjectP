# 1. 문서 개요
- 게임 플레이 시 플레이어의 판단에 따라 유동적으로 변할 수 있는 스탯 값을 모아두었습니다.
# 2. 플레이어 스탯
## 2-1. HP
>[!INFO] HP 수식
> **HP = 100 + X**
- 플레이어 체력으로 고정 값으로 체력이 증가합니다.
- 플레이어 체력은 기본 값으로 100을 가집니다.

## 2-2. 회복 증가
> [!INFO] 회복 증가 수식
> **체력 회복량 = 회복 아이템 \* (1 + X \* 0.01)**
- 플레이어 체력 회복은 스텟은 %단위로 증가하며 ==**플레이어의 체력이 회복되었을 때 영향**==을 받습니다.
## 2-3. 방어력
>[!INFO] 방어력 수식
> **적용 대미지 = 대미지 - 방어력**
- 방어력은 플레이어에 받을 피해를 감소합니다.
- 최대 값은 제한이 없으며 실제 적용될 대미지를 고정 값으로 줄입니다.

## 2-4. 방어력 (% 적용) 

> [!WARNING] 실제 적용되지 않을 스탯입니다.
> 상기 방어력 스탯이 고정 값이 아닌 % 적용으로 변경 시 사용 될 스팩입니다.

>[!INFO] 방어력 수식
> **실제 적용 대미지 = 대미지 \* (1 - (X / (500 + X)))**
- 방어력은 플레이어에 받을 피해를 감소합니다.
- 최대 값은 500이며 50%까지 감소가 가능합니다.

## 2-5. 아이템 드롭 확률 증가
- ==**아이템 드롭 확률 개정 후 작성 예정**==

# 3. 스킬 스탯
- 플레이어 측의 공격에 적용되는 모든 스탯입니다.
- 각 스킬에 공통 적용됩니다.
## 3-1. 공격력
- 공격력은 모든 공격에 고정 값으로 증가합니다.
## 3-2. 속성 공격력
 - 속성 공격력은 공격력과 별개로 특정 속성의 공격력만 증가합니다.
## 3-3. 대미지 증가
>[!INFO] 대미지 증가 수식
> **실제 적용 대미지 = (공격력 + 속성 공격력) * (1 + 대미지 증가%)**
 - 대미지 증가 공식은 합 적용으로 연산합니다.
 - 공격력을 기초로 하여 대미지를 % 단위로 증가합니다.

## 3-4. 쿨타임 감소
>[!INFO] 쿨타임 감소 수식
> **실제 스킬 쿨타임 = 스킬 쿨타임 \* ([1 - 쿨타임 감소1] * [1 - 쿨타임 감소2]...)**
- 쿨타임 감소는 곱 적용으로 연산합니다.
- 쿨타임 감소는 가장 높은 값 20개만 적용합니다.
## 3-5. 스킬 지속 시간 증가
>[!INFO] 스킬 지속 시간 증가 수식
> **실제 스킬 지속 시간 = 스킬 지속 시간 \* ([1 + X \* 0.005])**
- 스킬 지속 시간 증가는 합 적용으로 연산합니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
## 3-6. 스킬 범위 증가
>[!INFO] 스킬 범위 증가 수식
> **실제 스킬 범위 = 스킬 범위 \* (1 + 스킬 범위 증가)**
- 스킬 범위 증가는 합 적용으로 연산합니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.

# 4. [[⚔️ 스킬]] 스탯
- 모든 스킬 스탯은 블록이 배치된 점수에 따라 추가 스탯을 얻습니다.
- 속성 별로 부여되지 않고, 모든 스킬에 적용됩니다.
- 스킬 스탯 보너스 능력치는 같은 속성, 같은 스킬에만 적용합니다.
## 4-1. 탄환
- 1점 당 해당 속성의 공격력이 1 증가합니다.
- 10점마다 아래 보너스 능력치를 순서대로 반복하여 부여합니다.
	- 속성 공격력 증가 10
	- 탄환 스킬 쿨타임 감소 5%
	- 해당 속성 탄환 개수 증가 1개
	- 50점일 경우 **\[쿨타임 감소 5%]** 2번, **\[공격력 증가 5]** 2번, **\[해당 속성 탄환 개수 1개 증가]**가 적용됩니다.

## 4-2. 광역 탄환
- 1점 당 해당 속성의 공격력이 1 증가합니다.
- 10점마다 아래 능력치를 순서대로 반복하여 부여합니다.
	- 속성 공격력 증가 5
	- 광역 탄환 쿨타임 감소 5%
	- 스킬 지속 시간 증가 5%, 스킬 범위 증가 5% 
## 4-4. 지원
 - 1점 당 해당 속성의 공격력이 1 증가합니다.
 - 10점 마다 아래 보너스 능력치를 순서대로 반복하여 증가합니다.
	 - 속성 공격력 증가 5
	 - 지원 쿨타임 감소 5%
	 - 지원 크리쳐 개수 증가 1개
