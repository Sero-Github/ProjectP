# 1. 기획 의도
- 일반적인 [[⚔️ 스킬]]을 강화하는 수단으로 같은 스킬을 사용하지만 속성에 따라 다른 효과를 주도록 의도 되었습니다.
- 의도적으로 스킬 블록의 가짓수를 늘리기 위하여 기획되었습니다.
- 플레이어에게 여러 색상이 사용되는 이유를 설득시키기 위한 수단입니다.
# 2. 속성 정의
- 속성은 [[🧱 블록]]의 색상에 영향을 미치며, 공격 스킬의 대미지 계산에 영향을 줍니다.
- 속성은 공격의 특성과, 몬스터의 약점에 따라 조정됩니다.
- 몬스터는 한 가지 속성에 대해 대미지를 입을 경우 해당 속성을 갖게 됩니다.
- 다른 속성의 공격을 받았을 때, 아래의 설명에서 언급이 없다면, 피해 받은 속성의 색으로 변화하며 속성이 변경됩니다. 이를 ==**속성 주입**==이라고 합니다. ^d8xl
	- 단, 몬스터는 주황색 속성을 가질 수 없습니다.
	- 속성은 다른 속성을 주입하지 않으면 지속적으로 해당 속성을 가지게 됩니다.
	- 영역 또는 범위형 공격에 걸쳐서 지속적으로 속성이 주입되며 변경되어야 하는 경우, 영역이 넓은 곳의 속성을 주입합니다.
		- 단발성 공격은 여기에 해당하지 않습니다.
- [[📊 스탯#3-2. 속성 공격력 ★|속성 공격력]]이 가장 높은 속성은 ==**주 속성**==이라고 합니다. ^4fom
	- 단, 주황색 속성이 주 속성일 경우 다음 속성이 주 속성이 되며, 다음 속성이 없을 경우 빨간색 속성이 주 속성으로 변경됩니다.
# 3. 속성 종류
### 3-1. 빨강(폭발)
- 색상 코드는 <span class="red">FFDDDD</span> 코드를 사용합니다.
- 빨간색은 불 또는 폭발 속성으로 사용합니다.
- 빨간색 속성이 주입되는 즉시 폭발이 발생하며 주변 몬스터에게 [[📊 스탯#3-2. 속성 공격력 ★|속성 공격력]]에 비례한 대미지를 줍니다.
	- 폭발 대미지로 피격된 몬스터는 불 속성이 주입되지 않습니다.
	- 폭발 대미지는 속성 대미지와 같습니다.
- 폭발 대미지의 이펙트는 https://www.youtube.com/watch?v=baTgOtfHp-4 영상의 0~1초 부분과 같이 빨간색 선을 가진 원이 퍼집니다.
### 스탯 리스트
| 스탯        | 수치  | 조절 위치                                       | 변수형   |
| --------- | --- | ------------------------------------------- | ----- |
| 폭발 대미지 계수 | 0.5 |                                             | float |
| 폭발 범위     | 1   | `ElementSettings.asset` · `explosionRadius` | float |

## 3-2. 주황(강화)
- 색상 코드는 <span class="orange">FFEEDD</span> 코드를 사용합니다.
- 주황색은 강화 속성으로 사용합니다.
- 피격된 적이 가진 속성을 한 번 더 발생시키며, **\[현재 주입된 속성 대미지 + 주황 속성의 대미지]** 를 줍니다. 이는 스킬 대미지 적중 시 적용합니다.
	- 몬스터에게 속성을 주입하지 않습니다.
	- 빨간색 속성을 가진 적을 타격 시 폭발이 한번 더 발생합니다.
	- 노란색 속성을 가진 적을 타격 시 [[⚡ 속성#^r6f3|감전 공격]] 효과가 한 번 더 발생합니다.
	- 초록색 속성을 가진 적을 타격 시 효과가 강화되며 효과 중첩은 최대 한 번 중첩됩니다.
	- 파란색 속성을 가진 적을 타격 시 효과가 강화되며 효과 중첩은 최대 한 번 중첩됩니다.
	- 보라색 속성을 가진 적을 타격 시 독이 중첩되며, 최대 다섯 번 중첩됩니다.
	- 회색 속성을 가진 적을 타격 시 넉백이 1.5배 더 발생합니다.

| -------- | --- | ----------------------------------------------------- | ----- |
| 회색 넉백 배율 | 1.5 | `ElementSettings.asset` · `orangeKnockbackMultiplier` | float |
## 3-3. 노랑(감전)
 - 색상 코드는 <span class="yellow">FFFFC8</span> 코드를 사용합니다.
 - 노란색은 전기 속성으로 사용합니다.
 - 노란색 속성이 주입되면, 피격된 대상의 반경을 탐색 후 대미지를 줍니다. 이를 반복하여 가장 많은 적을 타격할 수 있는 기준으로 타격합니다. 이를 ==**감전 공격**==이라고 칭합니다. ^r6f3
	- 리그 오브 레전드의 스태틱의 단검과 같은 메커니즘으로 동작합니다.
	- [[⚡ 속성#^r6f3|감전 공격]]을 당한 적은 [[⚡ 속성#^d8xl|속성 주입]]이 되지 않습니다.
	- [[⚡ 속성#^r6f3|감전 공격]]은 기본적으로 3명의 적을 공격하며 노란색 속성의 [[🧱 블록#^fdbf|블록 점수]] 100당 1명을 추가적으로 추가 공격할 수 있습니다.
		- 최대 10명의 적까지 감전 공격을 할 수 있습니다.
	- [[⚡ 속성#^r6f3|감전 공격]]은 노란색 [[📊 스탯#3-2. 속성 공격력 ★|속성 공격력]]에 비례한 대미지를 입힙니다.
- 노란색 속성이 주입된 상태에서 3초 후 다시 [[⚡ 속성#^r6f3|감전 공격]]을 합니다.

| 감전 공격 대상 증가 필요 블록 점수 | 100  |       | int   |
## 3-4. 초록(둔화)
- 색상 코드는 <span class="green">DDFFDD</span> 코드를 사용합니다.
- 초록색은 풀, 둔화, 점액 속성으로 사용합니다.
- 초록색 속성이 주입되면, 적의 이동 속도를 둔화합니다.
	- 초록색 속성을 가지는 동안 지속적으로 이동 속도가 둔화되어야 합니다.
	- 적의 이동 속도는 기본 10% + 초록색 속성 [[🧱 블록#^fdbf|블록 점수]] 100당 5%를 둔화합니다.
		- 초록색 속성 [[🧱 블록#^fdbf|블록 점수]]를 150을 가진 경우 15%가 느려져야 합니다.
		- 최대 40%까지 둔화할 수 있습니다.

| 이동 속도 둔화 최대치         | 0.4  |       | float |
| 이동 속도 둔화 증가 필요 블록 점수 | 100  |       | int   |
## 3-5. 파랑(방어력 감소)
- 색상 코드는 <span class="blue">DDF6FF</span> 코드를 사용합니다.
- 파란색은 물, 방어력 감소 속성으로 사용합니다.
- 파란색 속성이 주입되면, 방어력이 하락합니다.
	- 방어력 하락 순서는 스탯에 해당하는 값을 먼저 계산 후, 속성 값을 계산합니다.
	- 파란색 속성을 가지는 동안과 속성을 잃은 후 5초간 방어력 감소가 지속됩니다.
		- 파란색 속성을 잃고 5초 안에 다시 파란색 속성을 얻을 경우 중첩되지 않습니다.
	- 적의 방어력 감소는 기본 40%, 파란색 속성 [[🧱 블록#^fdbf|블록 점수]] 100당 10%를 얻습니다.
		- 최대 100%까지 얻을 수 있습니다.
### 스탯 리스트

| 방어력 감소 증가량         | 0.1 |       | float |

| 방어력 감소 증가 필요 블록 점수 | 100 |       | int   |
## 3-6. 보라(독)
- 색상 코드는 <span class="purple">DDDDFF</span> 코드를 사용합니다.
- 보라색은 독 속성으로 사용합니다.
- 보라색 속성이 주입되면, 지속적으로 ==**독 대미지**==를 줍니다. ^oxan
	- 보라색 속성을 가지는 동안 지속적인 [[⚡ 속성#^oxan|독 대미지]]를 받습니다.
	- [[⚡ 속성#^oxan|독 대미지]]는 1초 마다, [[📊 스탯#3-2. 속성 공격력 ★|속성 공격력]]의 3%를 줍니다.
	- 보라색 속성을 가진 상태로 주황색 또는 보라색 속성을 가진 스킬에 피격 시 최대 5회 중첩이 가능합니다.

| -------- | ---- | ----- | ----- |
| 독 대미지 계수 | 0.03 |       | float |
| 최대 중첩 수  | 5    |       | int   |

## 3-7. 회색(넉백)
- 색상 코드는 <span class="gray">DEDEDE</span> 코드를 사용합니다.
- 회색은 넉백 속성으로 사용합니다.
- 회색 속성이 주입되면, 적이 넉백됩니다.
	- 회색 속성이 주입되면 1초간 이동할 수 있는 이동 거리의 3배 거리를 넉백 당합니다.
		- 몬스터가 화면 밖으로 나갈 경우 삭제되지 않고 넉백된 거리만큼 이동해서 와야 합니다.

| 이동 속도 비례 넉백 거리 | 3.0 |       | float |
| 넉백 시간(초)       | 0.5 |       | float |
