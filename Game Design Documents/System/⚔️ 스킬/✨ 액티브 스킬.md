# 3. 액티브 스킬 종류
## 3-1. 회복
- 레벨에 따라 플레이어의 체력을 회복합니다.
- 최대 레벨은 10레벨로 고정합니다.
- 1레벨마다 회복량은 플레이어 체력의 5%가 회복되며, 10레벨인 경우 50%까지 회복됩니다.
- 쿨타임 감소 효과는 받지 않으며, 쿨타임은 30초를 고정으로 갖습니다.
### 스탯 리스트
| 스탯              | 수치   | 조절 위치 | 변수형   |
| --------------- | ---- | ----- | ----- |
| 쿨타임             | 30   |       | int   |
| 체력 비례 회복량       | 0.05 |       | float |
| 레벨 비례 체력 회복 증가량 | 0.05 |       | float |
## 3-2. 폭탄
- 적에게 대미지를 주는 폭탄입니다.
- 최대 레벨은 10레벨로 고정합니다.
- 쿨타임은 없으며 1개 라운드에서 1번만 사용 가능합니다.
- 대미지는 주 속성 대미지의 300%의 대미지를 가지며, 1레벨 마다 대미지 계수는 30%씩 오릅니다. 10레벨인 경우 600%의 계수를 갖습니다.
- 맵 전체의 적을 [[⚡ 속성#^4fom|주 속성]] 대미지를 입히며 현재 속성과 관련 없이 모든 적이 [[⚡ 속성#^d8xl|속성 주입]]됩니다.
- 연출은 다음과 같습니다.
	- 흰색이었던 배경 색이 해당 속성의 색으로 0.2초 내로 서서히 변경되며, 플레이어 캐릭터 기준으로 흰색 원이 퍼지며 이 원에 충돌된 적은 대미지를 입고 모든 적이 [[⚡ 속성#^d8xl|속성 주입]]됩니다.
		- https://youtu.be/X2rSbeKq0X0?si=CVk0SlMde2iXAqym&t=10
		- 해당 영상의 9~10초 사이입니다.

# 4. 액티브 블록 소모
- 액티브 블록은 얻는 경로가 한정적이므로 분해 또는 소모하기 전에 **SYSTEM_ACTIVE_SKILL_CONSUME "액티브 스킬 블록을 소모하고 있습니다. 그래도 진행하시겠습니까?"** 팝업을 띄우고, Yes Or No를 선택하도록 합니다.
