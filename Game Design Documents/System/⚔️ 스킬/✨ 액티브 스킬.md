# 2. 액티브 스킬 정의
- 액티브 스킬은 ==**액티브 블록**==을 가방에 배치하면 활성화되는 스킬입니다.
	- 액티브 블록은 [[🧱 블록]] 중 4칸, 5칸 블록이며, 4칸·5칸 블록은 액티브 블록 전용입니다.
	- 액티브 블록은 스탯, 공격 스킬, 속성을 가지지 않고 액티브 스킬 하나만 가집니다.
- 활성화된 액티브 스킬은 쿨타임을 가집니다.
- 액티브 블록은 보스 처치 시에만 얻을 수 있으며, 일반 몬스터에게서는 드롭되지 않습니다.
	- 자세한 내용은 [[🏰 스테이지#2. 스테이지 구성]]을 따릅니다.
<span class="will-work">발동 방식(쿨타임마다 자동 발동 / 플레이어 입력), 같은 액티브 블록 중복 배치 가능 여부, 병합·강화 가능 여부 작성 예정</span>
