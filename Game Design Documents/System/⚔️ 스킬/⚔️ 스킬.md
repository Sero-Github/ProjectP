# 1. 기획 의도
- 플레이어가 가진 [[🧱 블록]]을 고를 때에 우선 순위를 정할 수 있도록 도와주는 장치입니다.
- 또한, 블록을 배치한 결과로 전투 화면이 달라지는 경험을 얻어야 합니다.
# 2. 스킬 정의
- 스킬은 공격 스킬과 스킬 속성으로 나누어집니다.
- 공격 스킬은 **어떻게 적을 타격하는가**에 초점이 맞춰집니다.
- 속성 부여는 **타격한 적을 어떻게 대미지를 주는가**에 초점이 맞춰집니다.
# 3. 공격 스킬
- 하기에 기술될 공격 스킬 중 한 종류가 랜덤하게 [[🧱 블록]]에 부여됩니다.
- 모든 공격 스킬은 하기 [[⚔️ 스킬#4. 속성]]이 부여되며 모든 색과 부가 효과는 속성에 따라 부여됩니다.
- 모든 공격이 화면 밖으로 벗어나면, 삭제되어야 합니다.
- 공격 스킬을 배치하기 전에는 무속성 탄환을 지속적으로 발사하며, 속성을 가진 탄환 배치 시 무속성 탄환은 발사하지 않습니다.
## 3-1. 탄환
### 모티브
- 매직 서바이벌의 마력탄을 모티브로 구상하였습니다.
- 외형도 이와 동일합니다.
### 상세
- ==탄환==은 직사각형의 속성을 가진 탄환을 우선 순위에 따라 자동 사출됩니다.
- 동시에 탄환이 사출 될 때 몬스터는 중복하여 타게팅하지 않아야 합니다.
- 탄환이 사출될 때 쿨타임이 흐릅니다.
- 관통력을 N가질 때 마다 N번의 적을 관통할 수 있습니다.
### Scriptable Object
- 재사용 대기 시간(float) : 1.5
- 이동 속도(float) : 5
- 동시 발사 개수(int) : 1
- 관통력(int) : 1
## 3-2. 광역 탄환
### 상세
- ==광역 탄환==은 탄환과 외형은 같지만, 소멸 시 원형의 ==공격 지대==를 생성합니다.
- 광역 탄환은 사출될 때 쿨타임이 흐릅니다.
- 공격 지대가 생성되면, 유지 시간이 흐릅니다.
- 공격 지대가 생성될 때 작은 원형이 점점 커지면서 생성됩니다.
- 공격 지대 유지 시간이 지나면 소멸되며, 작아지면서 소멸됩니다.
- 공격 지대는 각 개체에게 1초마다 대미지를 줍니다. (몬스터 객체 내부 쿨타임)
	- 객체 내부 쿨타임이여도 다른 공격 지대에 들어설 시 바로 대미지를 입으며 다시 내부 쿨타임이 돌아갑니다.
- 공격 지대가 다른 색으로 겹치면 최근 생긴 색으로 덮습니다. (공격 지대는 다중으로 처리가 되지 않습니다.)
### Scriptable Object
- 재사용 대기 시간(float) : 7
- 공격 지대 유지 시간(float) : 2
- 이동 속도(float) : 5
- 공격 지대 지름(int) : 20
## 3-3. 지형(보류)
### 모티브
- 지형은 리그 오브 레전드 - 트런들 E를 모티브로 구상하였습니다.
### 상세
- ==지형==은 쿨타임과 유지 시간을 가집니다. 
	- 쿨타임은 지형이 생성되었을 때 흘러갑니다.
	- 유지 시간은 최초 생성 시 시간이 흘러갑니다.
- 지형은 생성될 때 작은 원형이 점점 커지면서 생성됩니다.
- 지형 유지 시간이 지나면 소멸되며, 작아지면서 소멸됩니다.
- 지형은 중심점을 기준으로 원형의 공격 범위를 가집니다.
- 지형은 화면의 랜덤한 위치에 생성 되며, 공격 범위를 포함하여 화면 밖을 나갈 수 없습니다.
- 지형은 몬스터와 같이, 임의 공격 피격 시 다른 속성이 주입 될 수 있습니다.
- 지형은 몬스터와 충돌할 수 없으며, 몬스터는 지형을 피해서 이동해야 합니다.
### Scriptable Object
- 재사용 대기 시간(float)
- 지형 유지 시간(float)
- 지형 크기 지름(int)
- 범위 크기 지름(int)
## 3-4. 지원
- 플레이어를 지원하는 작은 원형 크리쳐를 ==지원 크리쳐==라 합니다.
- 지원 크리쳐는 스탯에 따라 생성합니다.
### 모티브
- 지원은 다음을 모티브로 구상하였습니다.
	- 스타크래프트 - 캐리어, 인터셉터
	- 리그 오브 레전드 - 신지드 Q
	- 리그 오브 레전드 - 나르 Q (이동 궤적)
### 생애 주기
- 지원 크리쳐는 자체적으로 쿨타임을 가지며, 다음과 같은 행동을 반복합니다.
	- 1. 우선 순위에 따른 적을 탐색 후 타겟을 향해 직선으로 이동합니다.
	- 2. 크리쳐가 몬스터 위치까지 도달하고 감속됩니다.
	- 3. 몬스터 크기 만큼 감속한 상태로 이동하고, 잠시 뒤 플레이어에게 이동합니다.
	- 4. 쿨타임 대기
- 지원 크리쳐가 이동한 궤적은 색 속성을 가지고, 에어 브러시와 같은 효과를 흩뿌립니다.
### Scriptable Object
- 재사용 대기 시간(float) : 10
- 이동 속도(float) : 5
- 궤적 유지 시간(float) : 5
# 4. 우선 순위
- 모든 공격 스킬은 공격하는 우선 순위를 각각 지정할 수 있습니다.
- 우선 순위는 옵션으로 자유롭게 지정할 수 있으며, **기본 값은 근거리**로 지정합니다.
- 우선 순위의 리스트는 다음과 같습니다.
	- 근거리
	- 원거리
	- 위협 우선
## 4-1. 근거리
- 플레이어를 기준으로 가장 가까운 적을 탐색하여 해당 적을 타겟으로 지정합니다.
## 4-2. 원거리
- 플레이어를 기준으로 가장 먼 적을 탐색하여 해당 적을 타겟으로 지정합니다.
## 4-3. 위협 우선
- 최대 HP가 가장 높은 적을 우선으로 탐색하여 해당 적을 타겟으로 지정합니다.
