# 1. 기획 의도
- 플레이어가 가진 [[🧱 블록]]을 고를 때에 우선 순위를 정할 수 있도록 도와주는 장치입니다.
- 또한, 블록을 배치한 결과로 전투 화면이 달라지는 경험을 얻어야 합니다.
# 2. 스킬 정의
- 스킬은 공격 스킬과 스킬 속성으로 나누어집니다.
- 스킬은 **어떻게 적을 타격하는가**에 초점이 맞춰집니다.
- 속성은 **타격한 적을 어떻게 대미지를 주는가**에 초점이 맞춰집니다.
# 3. 공격 스킬
- 하기에 기술될 공격 스킬 중 한 종류가 랜덤하게 [[🧱 블록]]에 부여됩니다.
- 모든 공격 스킬은 하기 [[⚔️ 스킬#4. 속성]]이 부여되며 모든 색과 부가 효과는 속성에 따라 부여됩니다.
- 속성이 다르더라도 같은 스킬이라면 [[🧱 블록#^fdbf|블록 점수]]는 공유됩니다.
	- 빨간색 탄환 스킬 3점, 노란색 탄환 스킬 3점에 해당하는 블록을 두 개 배치한 경우 다음과 같은 스탯을 얻습니다.
	- 빨간색 속성 대미지 3점
	- 노란색 속성 대미지 3점
	- 탄환 스킬 점수 3점
- 같은 스킬 중 다른 속성의 스킬이 사용되어야 하는 경우 재사용 대기 시간의 10% 간격으로 텀을 두어야 합니다.
	- 재사용 대기 시간이 1.5초, 두 개의 속성을 가진 동일 스킬을 사용하는 경우 다음과 같습니다.
	- 0.00초 : 빨간색 속성 스킬 사용
	- 0.15초 : 노란색 속성 스킬 사용
- 모든 공격이 화면 밖으로 벗어나면, 삭제되어야 합니다.
- 공격 스킬을 배치하기 전에는 무속성 탄환을 지속적으로 발사하며, 속성을 가진 탄환 배치 시 무속성 탄환은 발사하지 않습니다.
	- 무속성 탄환은 블록 점수가 1인 탄환을 발사하는 것을 기준으로 합니다.
- 공격 스킬의 대미지는 다음과 같이 계산합니다.
	- 공격력 + 속성 공격력을 구하고 이는 스킬의 대미지 계수와 곱합니다. 
## 3-1. 탄환
- 게임에서 가장 최소한으로 구성될 수 있는 공격입니다.
### 모티브
- 매직 서바이벌의 마력탄을 모티브로 구상하였습니다.
- 외형도 이와 동일합니다.
### 상세
- ==**탄환**==은 직사각형의 속성을 가진 탄환을 우선 순위에 따라 자동 사출되며 타겟된 적에게 직선 운동을 하여 날아갑니다. ^onlh
- 동시에 탄환이 사출 될 때 몬스터는 중복하여 타겟되지 않아야 합니다.
- 탄환이 사출될 때 쿨타임이 흐릅니다.
- 관통력을 N가질 때 마다 N번의 적을 관통할 수 있습니다.
	- 1의 관통력이 있다면, 1마리의 적을 타격 후 소멸되어야 합니다.
### 스탯 리스트

| 이름            | 수치  | 조절 위치                                    | 변수형   |
| ------------- | --- | ---------------------------------------- | ----- |
| 재사용 대기 시간 (초) | 1.5 | `Bullet_Basic.asset` · `cooldown`        | float |
| 이동 속도         | 5.0 | `Bullet_Basic.asset` · `moveSpeed`       | float |
| 탄환 대미지 계수     | 1.0 |                                          | float |
| 동시 발사 개수      | 1   | `Bullet_Basic.asset` · `projectileCount` | int   |
| 관통력           | 1   | `Bullet_Basic.asset` · `pierce`          | int   |
### 블록 점수에 따른 보너스
- [[⚔️ 스킬#3-1. 탄환|탄환]] 블록의 스킬 점수 1점 당 현재 블록의 속성에 따라 [[📊 스탯#3-2. 속성 공격력|속성 공격력]] 스탯을 1을 얻습니다.
- 10점마다 아래 보너스 능력치를 순서대로 반복하여 부여합니다.
	- 탄환 공격력 증가 10
	- 탄환 스킬 쿨타임 감소 5%
	- 50점일 경우 **\[탄환 공격력 증가 10]** 2번, **\[탄환 스킬 쿨타임 감소 5%]** 2번이 적용됩니다.
- 50점 마다 위와 관계 없이 아래 능력치를 반복하여 부여합니다.
	- 탄환 동시 발사 개수 증가 1
## 3-2. 광역 탄환
- 자동 공격을 통해 범위형 공격을 구성하기 위해 필요한 스킬입니다.
### 상세
- ==**광역 탄환**==은 탄환과 외형은 같지만, 광역 탄환이 소멸 시 원형의 ==**속성 지대**==를 생성합니다. ^haeg
- [[⚔️ 스킬#^haeg|광역 탄환]]은 사출될 때 쿨타임이 흐릅니다.
- [[⚔️ 스킬#^haeg|속성 지대]]가 생성되면, 유지 시간이 흐릅니다.
- [[⚔️ 스킬#^haeg|속성 지대]]가 생성될 때 작은 원형이 점점 커지면서 생성됩니다.
- [[⚔️ 스킬#^haeg|속성 지대]] 유지 시간이 지나면 소멸되며, 작아지면서 소멸됩니다.
- [[⚔️ 스킬#^haeg|속성 지대]]는 각 개체에게 1초마다 대미지를 줍니다. (몬스터 객체 내부 쿨타임)
	- 객체 내부 쿨타임이여도 다른 공격 지대에 들어설 시 바로 대미지를 입으며 다시 내부 쿨타임이 돌아갑니다.
- 
- [[⚔️ 스킬#^haeg|속성 지대]]가 다른 색으로 겹치면 최근 생긴 색으로 덮습니다. [[⚔️ 스킬#^haeg|속성 지대]]는 다중으로 처리가 되지 않습니다.

| 이동 속도         | 3.0 |       | float |
| 탄환 대미지 계수     | 0.8 |       | float |
| 속성 지대 대미지 계수  | 0.1 |       | float |
| 지대 생성 시간(초)   | 0.5 |       | float |
| 지대 지속 시간(초)   | 2.0 |       | float |
| 지대 소멸 시간(초)   | 0.5 |       | float |
| 지대 지름         | 20  |       | float |
### 블록 점수에 따른 보너스
- [[⚔️ 스킬#^haeg|광역 탄환]] 블록의 스킬 점수 1점 당 현재 블록의 속성에 따라 [[📊 스탯#3-2. 속성 공격력|속성 공격력]] 스탯을 1을 얻습니다.
- 10점마다 아래 능력치를 순서대로 반복하여 부여합니다.
	- [[⚔️ 스킬#^haeg|속성 지대]] 공격력 증가 5
	- 광역 탄환 스킬 쿨타임 감소 5%
	- 스킬 지속 시간 증가 5%, 스킬 범위 증가 5% 
## 3-3. 🚧 지형(보류)
> [!NOTE] 보류
> 지형 스킬은 보류된 사양입니다. 드롭되는 공격 스킬에 포함되지 않습니다.
### 모티브
- 지형은 리그 오브 레전드 - 트런들 E를 모티브로 구상하였습니다.
### 상세
- ==지형==은 쿨타임과 유지 시간을 가집니다. 
	- 쿨타임은 지형이 생성되었을 때 흘러갑니다.
	- 유지 시간은 최초 생성 시 시간이 흘러갑니다.
- 지형은 생성될 때 작은 원형이 점점 커지면서 생성됩니다.
- 지형 유지 시간이 지나면 소멸되며, 작아지면서 소멸됩니다.
- 지형은 중심점을 기준으로 원형의 공격 범위를 가집니다.
- 지형은 화면의 랜덤한 위치에 생성 되며, 공격 범위를 포함하여 화면 밖을 나갈 수 없습니다.
- 지형은 몬스터와 같이, 임의 공격 피격 시 다른 속성이 주입 될 수 있습니다.
- 지형은 몬스터와 충돌할 수 없으며, 몬스터는 지형을 피해서 이동해야 합니다.
### Scriptable Object
- 재사용 대기 시간(float)
- 지형 유지 시간(float)
- 지형 크기 지름(int)
- 범위 크기 지름(int)
## 3-4. 지원
- 게임이 진행되며 탄환만 발사하는 것이 아닌 다른 개체가 나를 도와주는 경험을 받기 위해 만들어진 스킬입니다.
### 정의
- ==**지원**== 스킬은 플레이어를 지원하는 작은 원형 크리쳐를 얻습니다. 이를 ==**지원 크리쳐**==라 합니다. ^lwvl
- [[⚔️ 스킬#^lwvl|지원 크리쳐]]는 스탯에 따라 생성합니다.
- [[⚔️ 스킬#^lwvl|지원 크리쳐]]는 플레이어 캐릭터 위에 출력되지 않아야 합니다. 쿨타임 중 플레이어 캐릭터 뒤에 숨어있을 수 있습니다.
### 모티브
- 지원은 다음을 모티브로 구상하였습니다.
	- 스타크래프트 - 캐리어, 인터셉터
	- 리그 오브 레전드 - 신지드 Q
	- 리그 오브 레전드 - 나르 Q (이동 궤적)
### 외형
- [[⚔️ 스킬#^lwvl|지원 크리쳐]]는 다음 웹 페이지의 커서와 같이 생겼으며 이동 시 꼬리가 생깁니다.
- [[Attach/Support_Element.html]]
### 생애 주기
- [[⚔️ 스킬#^lwvl|지원 크리쳐]]는 자체적으로 쿨타임을 가지며, 다음과 같은 행동을 반복합니다.
	- 1. 우선 순위에 따른 적을 탐색 후 타겟을 향해 직선으로 이동합니다.
	- 2. [[⚔️ 스킬#^lwvl|지원 크리쳐]]가 몬스터 위치까지 도달하고 감속됩니다.
	- 3. 몬스터 크기 만큼 감속한 상태로 이동하고, 잠시 뒤 플레이어에게 이동합니다.
	- 4. 쿨타임 대기
- [[⚔️ 스킬#^lwvl|지원 크리쳐]]가 이동한 ==**궤적**==은 색 속성을 가지고, 에어 브러시와 같은 효과를 흩뿌립니다. 이는 속성 대미지를 입힙니다. ^n5eb

# 4. 우선 순위
- 모든 공격 스킬은 공격하는 ==**우선 순위**==를 각각 지정할 수 있습니다. ^zrr3
- [[⚔️ 스킬#4. 우선 순위|우선 순위]]는 옵션으로 자유롭게 지정할 수 있으며, 값이 없을 경우 **기본 값은 근거리**로 지정합니다.
- [[⚔️ 스킬#4. 우선 순위|우선 순위]]의 리스트는 다음과 같습니다.
	- 근거리
	- 원거리
	- 위협 우선
## 4-1. 근거리
- 플레이어를 기준으로 가장 가까운 적을 탐색하여 해당 적을 타겟으로 지정합니다.
## 4-2. 원거리
- 플레이어를 기준으로 가장 먼 적을 탐색하여 해당 적을 타겟으로 지정합니다.
## 4-3. 위협 우선
- 최대 HP가 가장 높은 적을 우선으로 탐색하여 해당 적을 타겟으로 지정합니다.
