# 1. 문서 개요
- 게임 플레이 시 플레이어의 판단에 따라 유동적으로 변할 수 있는 스탯 값을 모아두었습니다.
- 블록으로 얻을 수 있는 스탯은 ★로 표시합니다.
# 2. 플레이어 스탯
## 2-1. HP ★
>[!INFO] HP 수식
> **HP = 100 + X**
- 플레이어 체력으로 고정 값으로 체력이 증가합니다.
- 블록 점수 1당 1의 스탯을 얻습니다.
- 플레이어 체력은 기본 값으로 100을 가집니다.
## 2-2. 방어력 ★
>[!INFO] 방어력 수식
> **적용 대미지 = 대미지 - 방어력**
- 방어력은 플레이어에 받을 피해를 감소합니다.
- 최대 값은 제한이 없으며 실제 적용될 대미지를 고정 값으로 줄입니다.
- 블록 점수 1당 1의 스탯을 얻습니다.
- 만약, 적용 대미지가 음수가 될 경우, 해당 대미지는 무시되어야 합니다.

## 2-3. 방어력 (% 적용)
> [!WARNING] 실제 적용되지 않을 스탯입니다.
> 상기 방어력 스탯이 고정 값이 아닌 % 적용으로 변경 시 사용 될 스펙입니다.

>[!INFO] 방어력 수식
> **실제 적용 대미지 = 대미지 \* (1 - (X / (500 + X)))**
- 방어력은 플레이어에 받을 피해를 감소합니다.
- 최대 값은 500이며 50%까지 감소가 가능합니다.

## 2-4. 아이템 드롭 확률 증가
- ==**아이템 드롭 확률 개정 후 작성 예정**==
## 2-5. 무적 시간
- 실제 얻을 수 있는 스탯이 아닌 공격을 받을 수 있는 간격을 정합니다.
- 대미지를 입어 피격당하는 경우 반드시 0.3초간은 무적 처리가 되어야 합니다.
# 3. 스킬 스탯
- 플레이어 측의 공격에 적용되는 모든 스탯입니다.
- 각 스킬에 공통 적용됩니다.
## 3-1. 공격력 ★
- 공격력은 모든 공격에 고정 값으로 증가합니다.
- 블록 점수 1당 1의 스탯을 얻습니다.
## 3-2. 속성 공격력 ★
 - 속성 공격력은 공격력과 별개로 특정 속성의 공격력만 증가합니다.
 - 블록 점수 1당 3의 스탯을 얻습니다.
## 3-3. 대미지 증가 ★
>[!INFO] 대미지 증가 수식
> **실제 적용 대미지 = (공격력 + 속성 공격력) \* 스킬/속성 공격력 계수 \* (1 + 대미지 증가%)** ^s8b8
 
- 대미지 증가 공식은 합 적용으로 연산합니다.
- [[⚔️ 스킬]] 또는 [[⚡ 속성]]에 따른 대미지 피격 시 모든 대미지 연산은 위 공식을 통해 사용합니다.
- 공격력을 기초로 하여 대미지를 % 단위로 증가합니다.
- 블록 점수 1당 1%의 스탯을 얻습니다.
## 3-4. 쿨타임 감소 ★
>[!INFO] 쿨타임 감소 수식
> **실제 스킬 쿨타임 = 스킬 쿨타임 \* ([1 - 쿨타임 감소1] * [1 - 쿨타임 감소2]...)**
- 쿨타임 감소는 곱 적용으로 연산합니다.
- 쿨타임 감소는 가장 높은 값 20개만 적용합니다.
- 최대 쿨타임 상한선은 스킬 쿨타임의 80%까지 줄어들 수 있습니다.
	- 스킬 쿨타임이 1초라면, 최대 0.2초까지 줄어들 수 있습니다.
- 블록 점수 1당 1%를 얻습니다.
	- 블록이 병합되어 있는 경우 이는 합하여 연산합니다.
## 3-5. 스킬 지속 시간 증가 ★
>[!INFO] 스킬 지속 시간 증가 수식
> **실제 스킬 지속 시간 = 스킬 지속 시간 \* ([1 + X])**
- 스킬 지속 시간 증가는 합 적용으로 연산합니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
- 블록 점수 1당 1%를 얻습니다.
- 적용 스킬 리스트는 다음과 같습니다.
	- [[⚔️ 스킬#^haeg|속성 지대]]
	- [[⚔️ 스킬#^n5eb|궤적]]
## 3-6. 스킬 범위 증가 ★
>[!INFO] 스킬 범위 증가 수식
> **실제 스킬 범위 = 스킬 범위 \* (1 + 스킬 범위 증가)**
- 스킬 범위 증가는 합 적용으로 연산합니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
- 블록 점수 1당 1%를 얻습니다.
