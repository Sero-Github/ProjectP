# 1. 기획 의도
- 블록 병합은 같은 스탯을 가지며 모양이 같거나 유사한 블록을 하나로 만들어, 가능한 작은 가방에 높은 스탯을 얻을 수 있도록 하는 기능입니다.
- V2를 기준으로 [[🧱 블록 강화]]의 사양 개발을 진행하지 않고 게임의 루프가 정상적으로 진행되는지 확인이 필요하기 때문에, 블록의 잔여 회수를 삭제합니다.
# 2. 블록 병합 정의
- 블록 병합은 두 개의 [[🧱 블록]]을 합쳐 블록이 가진 고유 능력치를 강화하는 시스템입니다.
# 3. 블록 병합 조건
- 블록 병합은 등급이 서로 같아야 합니다.
- 같은 스탯을 가지거나, 스킬, 속성이 모두 같으면 블록을 병합할 수 있습니다.
- 블록 병합은 ==**큐브**==를 일정 소모하여야 합니다.
	- ~~골드 소모량은 다음과 같은 CSV 파일로 구성됩니다.~~
		- ~~블록 등급, 사용 골드로 구성됩니다.~~
	- V2를 기준으로 사용 재화를 다음과 같이 처리합니다.
		- 조합 후 최종 블록 점수 * 20
- ~~잔여 블록 병합 횟수가 남아있어야 합니다.~~
	- V2를 기준으로 블록 병합은 무제한으로 처리합니다.
# 4. 블록 병합 구성
- 블록 병합 시 좌측의 블록은 **병합할 블록**입니다.
	- **병합할 블록**은 우측의 블록의 효과를 받는 것으로 강화 됩니다.
- 블록 병합 시 우측의 블록은 **소모 블록**입니다.
	- **소모 블록**은 병합을 하지 않은 **원본 블록**만 등록할 수 있습니다.
# 5. 블록 병합 불가능 조건
- 블록 병합 시 두 개의 블록이 서로 인접하여 있지 않다면 병합이 불가능합니다.
- 병합한 블록의 결과가 최대 크기가 가로 3칸, 세로 3칸 초과 시 병합이 불가능합니다.
# 6. 블록 병합 완료
- 블록 병합 시 병합된 두 블록의 능력치를 합산하여 얻습니다.
- 블록 병합 시 두 개의 블록을 합친 블록을 결과물로 얻습니다.

# 7. UI/UX
1. 인벤토리가 출력되어야 합니다.
2. 병합할 블록을 올려둘 수 있는 두 개의 3x3 공간이 필요합니다. 이를 ==**병합 칸**==이라고 합니다.
	1. 병합할 블록을 선택하는 것은 다음 두 가지 방법으로 선택할 수 있습니다.
	2. 인벤토리에 있는 블록을 클릭할 경우 1번째 ==**병합 칸**==으로 이동합니다.
		1. 만약 1번째 병합 칸에 임의 블록이 채워져 있다면 2번째 블록 칸으로 이동합니다.
	3. 인벤토리에 있는 블록을 드래그 드롭하여 임의 ==**병합 칸**==으로 이동합니다.
		1. 만약 해당 병합 칸에 다른 블록이 있다면, 서로 교체되어야 합니다.
3. 병합 결과물이 출력되는 3x3 공간이 필요합니다. 이를 ==**결과 칸**==이라고 합니다.
	1. ==**병합 칸**==에 블록이 모두 채워질 경우 다음 항목을 확인 후 결과가 출력되어야 합니다.
		1. 재화가 부족한 경우, **SYSTEM_MERGE_NOT_ENOUGH_CUBE "병합에 필요한 큐브가 부족합니다."** 메시지가 출력되어야 합니다. 결과물과 스탯은 보여주되 결과물은 가져갈 수 없어야 합니다.
		2. 블록이 인접하지 않아 병합이 불가능한 경우, **SYSTEM_MERGE_NO_ATTACH_BLOCK "인접한 블록이 있어야 합니다."** 메시지가 출력되어야 합니다.
		3. 서로 다른 스탯 또는 스킬이 있는 경우, **SYSTEM_MERGE_DIFFERENT_CORE "서로 다른 스탯이나 스킬을 가지고 있습니다."** 메시지가 출력되어야 합니다.
		4. 병합이 가능한 경우, 결과 칸에 병합이 완료된 형태의 블록과 스탯이 출력되어야 합니다.
			1. 이후 클릭 또는 드래그 드롭으로 가져가면 ==**병합 칸**==에있는 재료는 소멸처리되며 ==**결과 칸**==의 결과물을 인벤토리로 가져옵니다.
4. ==**병합 칸**==에 임의 블록이 배치된 상태에서 다른 화면으로 이동할 경우 ==**병합 칸**==에 배치된 블록은 등록 해제되고 인벤토리로 돌아가야 합니다.
	1. 병합이 가능한 상태지만, 직접 가져가지 않은 경우(3.1.4), 병합은 취소되며 병합이 진행되지 않습니다.
