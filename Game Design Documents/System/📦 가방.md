# 1. 기획 의도
- 플레이어에게 가방은 열쇠로 풀 수 있는 자물쇠로 인식되어야 합니다.
	- 자물쇠라는 뜻은 다음과 같습니다.
		- 열쇠가 있어도 열쇠 구멍이 어디있는지 찾지 못하면 풀 수 없습니다. 이는 문제를 인식하였으나 문제를 해결 불가능한 것을 뜻합니다.
		- 다수의 와이어락으로 잠겨져 있다면 순차적으로 풀어야 한다는 의미입니다. 이는 문제를 인식하였으나 순서와 한계점이 있어, 한 번에 해결이 불가능한 것을 뜻합니다.
# 2. 가방 정의
- [[🧱 블록]]을 배치하여 능력치를 얻을 수 있는 공간 하나를 가방이라고 합니다.
- 가방은 레벨을 가지며 다음과 같은 기능을 지닙니다.
	- 가방 레벨을 올리기 위해서는 [[💎 큐브]]를 소모해야 합니다.
	- 가방 레벨이 오르며 가로, 세로 최대 칸 수가 증가되거나, 가방 개수가 늘어날 수 있습니다.
- ~~하나의 가방에 정해진 [[📊 스탯]]이 배치되어 있다면 시너지 효과를 얻을 수 있습니다.~~
	- 현재 버전에서는 제외되는 항목입니다.
- 가방의 정보는 CSV 파일로 관리되며 구성은 다음과 같습니다. ^e7bd
	- 가방이 존재하지 않는다면 0으로 저장됩니다.
	- 가방 레벨, 필요 큐브, 가방1 가로, 가방1 세로, 가방2 가로, 가방2 세로, 가방3 가로, 가방3 세로
		1. 1, 0, 3, 3, 0, 0, 0, 0
		2. 2, 500, 0, 3, 4, 0, 0, 0, 0
- 가방은 최대 3개까지 사용합니다.
- 가방에는 블록을 겹쳐서 배치할 수 없습니다.
- 가방에 등록된 블록은 인벤토리로 되돌릴 수 있습니다.
- 전투 중에도 가방 화면에 진입하여 지속적으로 배치를 변경할 수 있습니다.
# 4. UI/UX
- 인벤토리와 가방은 항상 같이 출력되어야 합니다.
- 인벤토리에서 가방으로 블록을 드래그하여 배치할 수 있어야 합니다.
- 가방에서 인벤토리로 블록을 드래그하여 배치 해제할 수 있어야 합니다.
- 가방은 여러개의 탭으로 1번 가방, 2번 가방 등으로 이동할 수 있어야 합니다. 탭은 무한정 개수가 늘어나도 UI 대응이 가능해야 합니다.
- 하나의 가방은 가로 7칸, 세로 5칸으로 구성되어야 합니다.
- 현재 가방에 배치된 블록의 스탯 총 합을 표시할 수 있어야 합니다.
- 모든 가방에 배치된 블록의 스탯 총 합을 표시할 수 있어야 합니다.
