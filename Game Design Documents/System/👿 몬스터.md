# 1. 문서 개요
- 플레이어의 적군으로 등장하는 개체들을 서술한 문서입니다.

# 2. 공통
## 2-1. 외형
- 몬스터의 유형에 따라 외형이 설정됩니다. 유형에 따라 기본형보다 상대적으로 나은 스탯을 가집니다.
	- 원형 - 기본 형태
	- 삼각형 - 원거리 공격 / 공격력↑, 체력↓, 방어력↓
	- 사각형 - 탱커 / 공격력↓, 체력↑, 방어력↑
	- 오각형 - 보스 또는 중간 보스 / 공격력↑, 체력↑, 방어력↑
		- 한 스테이지에서 등장할 수 있는 오각형 몬스터는 최대 5개로 제한합니다. (디자인 방향성 제한)
## 2-2. 스탯
- 모든 몬스터의 스탯은 스테이지 값에 따라 수식으로 값을 가집니다. 만약 소수점 이하가 나온다면 버림 처리를 합니다.
- 공격력, 체력, 방어력, 공격 속도, 이동 속도를 가집니다.

# 3. 생애 주기
## 3-1. 생성
- 모든 몬스터는 화면 밖 랜덤 위치에서 생성됩니다.
- 생성 된 이후 즉시 플레이어에게 최적의 거리를 계산하여 이동합니다.
	- 추후 지형지물 생성이 가능할 수 있습니다.
- 몬스터는 라운드 별로 정해진 개수만큼 생성되며 이는 CSV 파일로 관리합니다.
	- CSV 파일은 다음과 같이 구성됩니다.
	- 스테이지, 라운드, 원형 몬스터 개수, 삼각형 몬스터 개수, 사각형 몬스터 개수, 오각형 몬스터 개수
- 몬스터의 스탯은 배율과 현재 라운드 수치에 따라 계산합니다.
	- 현재 1스테이지 10라운드일 경우 10의 배율로 계산
	- 현재 2스테이지 1라운드일 경우 11의 배율로 계산 (1스테이지 별로 10라운드가 있을 경우)
## 3-2. 플레이어와 충돌
- 유형에 관계 없이 몬스터는 플레이어와 충돌 시 근접으로 공격한 판정을 가집니다.
- 근접 공격은 쿨타임이 적용됩니다.

# 4. 몬스터 유형
