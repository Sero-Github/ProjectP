# 1. 문서 개요
- 플레이어의 적군으로 등장하는 개체들을 서술한 문서입니다.
# 2. 몬스터 공통 사항
## 2-1. 몬스터 설정
- 몬스터의 유형에 따라 외형이 설정됩니다. 유형에 따라 기본형보다 상대적으로 나은 스탯을 가집니다.
-  한 스테이지에서 등장할 수 있는 오각형 몬스터는 최대 5개로 제한합니다. (디자인 방향성 제한)
- 모든 몬스터의 스탯은 소수점 이하는 버림 처리를 합니다.
- 모든 몬스터는 2초 동안 한 바퀴 회전합니다. 이는 지속적으로 반복됩니다.
## 2-2. 몬스터 스탯
- 몬스터의 방어력은 아래 수치를 계산 후 나온 대미지에서 방어력을 뺀 수치만큼 ![[📊 스탯#^s8b8]]
- 조절 위치: 원형 `EnemyData 1.asset`, 삼각형 `EnemyData 2.asset`, 사각형 `EnemyData 3.asset`, 오각형 `EnemyData 4.asset`

| 스탯     | 원형   | 삼각형          | 사각형    | 오각형       | 필드                  |
| ------ | ---- | ------------ | ------ | --------- | ------------------- |
| 유형     | 기본 적 | 변칙 이동형       | 탱커, 버퍼 | 중간 보스, 보스 | –                   |
| 공격 방식  | 근접   | 근접           | 근접     | 근접        | –                   |
| 이동 방식  | 직선   | 직선 + 간헐적 대각선 | 직선     | 미정        | –                   |
| 고정 HP  | –    | 1.0          | 1.0    | 20.0      | `baseHp`            |
| HP 배율  | 1.2  | 1.0          | 3.0    | 5.0       | `hpMultiplier`      |
| 고정 공격력 | –    | 1            | 1      | 1         | `baseAttack`        |
| 공격력 배율 | 1.0  | 1.2          | 0.8    | 2.1       | `attackMultiplier`  |
| 고정 방어력 | 0    | 0            | 3.0    | 10.0      | `baseDefense`       |
| 방어력 배율 | 1.5  | 1.0          | 2.0    | 5.0       | `defenseMultiplier` |
| 이동 속도  | 1.2  | 1.0          | 0.6    | 0.2       | `moveSpeed`         |
# 3. 생애 주기
## 3-1. 생성
- 모든 몬스터는 화면 밖 랜덤 위치에서 생성됩니다.
- 생성 된 이후 즉시 플레이어에게 최적의 거리를 계산하여 이동합니다.
	- 추후 지형지물 생성이 가능할 수 있습니다.
- 몬스터의 스탯은 배율과 현재 라운드 수치에 따라 계산합니다.
	- 현재 1스테이지 10라운드일 경우 10의 배율로 계산
	- 현재 2스테이지 1라운드일 경우 11의 배율로 계산 (1스테이지 별로 10라운드가 있을 경우)
## 3-2. 플레이어와 충돌
- 유형에 관계 없이 몬스터는 플레이어와 충돌 시 근접으로 공격한 판정을 가집니다.
- 근접 공격은 쿨타임이 적용됩니다.
## 3-3. 사망
- 몬스터 사망 시 [[🧱 블록]]을 랜덤으로 드롭합니다.
	- 상세 설명은 [[🧱 블록#4. 블록 드롭 로직]]에 작성되어 있습니다.
- 모든 몬스터가 사망 시 현재 주입된 속성에 따라 해당 색상의 파티클을 생성하며 사라집니다.
	- 파티클은 몬스터의 형태가 쪼개지며 각 파티클로 변화해야 합니다. - https://youtu.be/bd-53OouMWw?si=lOFaIRhGtWSA7d3w&t=16
	- 파티클은 가운데에서 바깥으로 발생하는 형태로 퍼져 나가야 합니다. - https://www.youtube.com/shorts/DeLvl-wWbmY
	- 각 파티클은 몬스터의 모양에 따라 원형 몬스터면 원형으로, 삼각형이면 삼각형으로 파티클이 생성되어야 합니다.
	- 생성되는 파티클은 모양이 제각각으로 출력될 수 있습니다. - https://www.youtube.com/watch?v=Z9oBqwzjlcs
	- 파티클은 1초간 지속되어야 합니다. 자연스럽게 파티클이 작아지며 사라져야 합니다.
# 4. 몬스터 유형
## 4-1. 원형
- 플레이어를 향해 직선 이동하는 기본형 적입니다.
## 4-2. 삼각형
- 플레이어를 향해 직선, 대각선 이동을 하는 회피형 적입니다.

| 스탯           | 수치                | 필드                 | 변수형   |
| ------------ | ----------------- | ------------------ | ----- |
| 대각선 이동 주기(초) | 5.0               | `coolMovement`     | float |
| 대각선 이동 거리    | 20.0 (이동 속도에 비례한) | `distanceMovement` | float |
## 4-3. 사각형
- 플레이어를 향해 직선 이동을 하며, 자신을 중심으로 원형의 범위 내에 이동 속도 또는 방어력 증가 버프를 줍니다.

| 스탯         | 수치                         | 필드                        | 변수형   |
| ---------- | -------------------------- | ------------------------- | ----- |
| 버프 유형      | 1 : 이동 속도 증가<br>2 : 방어력 증가 | `buffType`                | Enum  |
| 버프 반경      | 100.0                      | `buffDistance`            | float |
| 이동속도 버프 배율 | 1.5                        | `buffMoveSpeedMultiplier` | float |
| 방어력 증가 배율  | 1.2                        | `buffDefenceMultiplier`   | float |
## 4-4. 오각형
- 플레이어를 향해 직선 이동을 합니다. 타 몬스터 보다 높은 능력치를 가지며 [[🧱 블록#^81ve|액티브 블록을 드롭할 수 있습니다.]]
