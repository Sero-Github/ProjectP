# 1. 기획 의도
- 병합 횟수를 모두 사용한 블록을 강화하여 더 나은 스탯을 얻도록 합니다.
- [[🧱 블록 병합]]으로 원하는 모양을 맞춘 블록이 병합 횟수를 모두 사용한 뒤에도 계속 성장할 수 있도록 하기 위해 만들어질 기능입니다.
# 2. 블록 강화 정의
- 블록 강화는 블록의 점수를 올리는 시스템입니다.
- 강화 수치는 "**강**"으로 표기합니다.
	- 표기 규칙("**3합 2강**")은 [[🧱 블록#2. 블록 정의]]를 따릅니다.
	- 등급, n성, 돌파 등의 명칭은 사용하지 않습니다.
# 3. 블록 강화 조건
- 병합 횟수를 모두 사용한 블록(3합)만 강화할 수 있습니다.
- 최대 강화 수치는 5강입니다.

> [!QUESTION] 확인 필요
> 최대 강화 수치 5강은 회의 기록 중 한 쪽(B)에만 적혀 있어 확인이 필요합니다.

# 4. 블록 강화 결과
- 1강마다 강화 전 원본 점수의 20%가 더해집니다.
	- 원본 점수는 강화를 하지 않은 상태(3합 0강)의 블록 점수입니다.
	- 원본 점수가 100인 블록은 1강 120, 2강 140, 5강 200이 됩니다.

| 강화 수치 | 점수 (원본 100 기준) |
| ----- | -------------- |
| 0강    | 100            |
| 1강    | 120            |
| 2강    | 140            |
| 3강    | 160            |
| 4강    | 180            |
| 5강    | 200            |
