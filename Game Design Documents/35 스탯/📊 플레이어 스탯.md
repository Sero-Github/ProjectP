# 1. 기획 의도
- 게임 플레이 시 플레이어의 판단에 따라 유동적으로 변할 수 있는 스탯 값을 모아두었습니다.
- 블록으로 얻을 수 있는 스탯은 ★로 표시합니다.
- 기본 스탯은 Unity에서 Player 오브젝트의 `Player` 컴포넌트 > Stats(`UnitStats`)에서 고칩니다. 블록으로 얻는 값은 이 기본 스탯에 더해집니다.
# 2. 플레이어 스탯
## 2-1. HP ★
>[!INFO] HP 수식
> **HP = 100 + X**
- 플레이어 체력으로 고정 값으로 체력이 증가합니다.
- 블록 점수 1당 1의 스탯을 얻습니다.
- 플레이어 체력은 기본 값으로 100을 가집니다.
- 조절 위치: `UnitStats` · `maxHp`

## 2-2. 회복 증가 ★
> [!INFO] 회복 증가 수식
> **체력 회복량 = 회복 액티브 스킬의 회복량 \* (1 + X \* 0.01)**
- 플레이어 체력 회복은 스탯은 %단위로 증가하며 ==**플레이어의 체력이 회복되었을 때 영향**==을 받습니다.
- 체력 회복 수단은 [[✨ 액티브 스킬#3-1. 회복]]입니다. 회복 아이템은 사용하지 않습니다.
- 블록 점수 1당 1%의 스탯을 얻습니다.
- 조절 위치: `UnitStats` · `healIncrease`
## 2-3. 방어력 ★
>[!INFO] 방어력 수식
> **적용 대미지 = 대미지 - 방어력**
- 방어력은 플레이어에 받을 피해를 감소합니다.
- 최대 값은 제한이 없으며 실제 적용될 대미지를 고정 값으로 줄입니다.
- 블록 점수 1당 1의 스탯을 얻습니다.
- 만약, 적용 대미지가 음수가 될 경우, 해당 대미지는 무시되어야 합니다.
- 조절 위치: `UnitStats` · `defense`

## 2-4. 방어력 (% 적용)
> [!NOTE] 보류: 실제 적용되지 않을 스탯입니다.
> 상기 방어력 스탯이 고정 값이 아닌 % 적용으로 변경 시 사용 될 스펙입니다.

>[!INFO] 방어력 수식
> **실제 적용 대미지 = 대미지 \* (1 - (X / (500 + X)))**
- 방어력은 플레이어에 받을 피해를 감소합니다.
- 최대 값은 500이며 50%까지 감소가 가능합니다.

## 2-6. 무적 시간
- 실제 얻을 수 있는 스탯이 아닌 공격을 받을 수 있는 간격을 정합니다.
- 대미지를 입어 피격당하는 경우 반드시 0.3초간은 무적 처리가 되어야 합니다.
- 조절 위치: 없음

> [!QUESTION] 확인 필요
> 코드에서 무적 처리를 찾지 못했습니다. 피격 후 깜빡임(`Player` · `blinkDuration`) 동안에도 대미지를 받는다고 되어 있어, 무적 시간이 구현되었는지 확인이 필요합니다.
