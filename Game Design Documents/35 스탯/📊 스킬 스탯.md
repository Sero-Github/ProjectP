# 1. 기획 의도
- 게임 플레이 시 플레이어의 판단에 따라 유동적으로 변할 수 있는 스탯 값을 모아두었습니다.
- 블록으로 얻을 수 있는 스탯은 ★로 표시합니다.
- 모든 공격 스킬이 공유하는 스탯(2장)과 공격 스킬별 개별 스탯(3장)을 나누어 정리합니다. 스킬의 동작은 [[⚔️ 스킬]]을 따릅니다.
- 표의 "조절 위치"는 Unity에서 값을 고치는 곳입니다. `.asset` 파일은 Project 창에서 클릭해 Inspector에서 고치고, "코드 상수"는 코드를 고쳐야 합니다.

# 2. 공유 스탯
- 플레이어 측의 공격에 적용되는 모든 스탯입니다.
- 각 스킬에 공통 적용됩니다.
- 블록으로 얻는 스탯은 `BlockStatData.asset`에서 스탯별 "점수 1당 수치"를 고칩니다. 스탯 수치 = 블록 점수 × 이 값입니다.

| 스탯 | 기획 값 | 적용 방식 | 조절 위치 |
| --- | --- | --- | --- |
| 공격력 ★ | 블록 점수 1당 1 | 고정 값 | `BlockStatData` · `Attack` |
| 속성 공격력 | 블록 점수 1당 3 | 고정 값, 해당 속성만 | `BlockStatData` · `ElementAttack_1~7` |
| 대미지 증가 ★ | 블록 점수 1당 1% | 합 | `BlockStatData` · `DamageIncrease` |
| 쿨타임 감소 ★ | 블록 점수 1당 1% | 곱, 높은 값 20개만 | `BlockStatData` · `CooldownReduction`, 적용 개수는 코드 상수 `BlockStatTotals.MaxCooldownReductionCount` |
| 최소 쿨타임 | 미정 | – | 코드 상수 `BulletShooter.MinCooldown`, `SupportShooter.MinCooldown` |
| 스킬 지속 시간 증가 ★ | 블록 점수 1당 1% | 합 | `BlockStatData` · `SkillDurationIncrease` |
| 스킬 범위 증가 ★ | 블록 점수 1당 1% | 합 | `BlockStatData` · `SkillRangeIncrease` |
| 공격 지대 대미지 간격 | 1초 | 몬스터 객체 내부 쿨타임 | `AttackZoneSystem` 컴포넌트 · `hitInterval` |
| 스킬 대미지 계수 | 미정 (CSV로 관리) | – | 미정 |

## 2-1. 공격력 ★
- 공격력은 모든 공격에 고정 값으로 증가합니다.
- 블록 점수 1당 1의 스탯을 얻습니다.
## 2-2. 속성 공격력
 - 속성 공격력은 공격력과 별개로 특정 속성의 공격력만 증가합니다.
 - 블록 점수 1당 3의 스탯을 얻습니다.
## 2-3. 대미지 증가 ★
>[!INFO] 대미지 증가 수식
> **실제 적용 대미지 = (공격력 + 속성 공격력) * (1 + 대미지 증가%)**
 - 대미지 증가 공식은 합 적용으로 연산합니다.
 - 공격력을 기초로 하여 대미지를 % 단위로 증가합니다.
 - 블록 점수 1당 1%의 스탯을 얻습니다.

## 2-4. 쿨타임 감소 ★
>[!INFO] 쿨타임 감소 수식
> **실제 스킬 쿨타임 = 스킬 쿨타임 \* ([1 - 쿨타임 감소1] * [1 - 쿨타임 감소2]...)**
- 쿨타임 감소는 곱 적용으로 연산합니다.
- 쿨타임 감소는 가장 높은 값 20개만 적용합니다.
- 블록 점수 1당 1%를 얻습니다.
	- 블록이 병합되어 있는 경우 이는 합하여 연산합니다.

## 2-5. 스킬 지속 시간 증가 ★
>[!INFO] 스킬 지속 시간 증가 수식
> **실제 스킬 지속 시간 = 스킬 지속 시간 \* ([1 + X])**
- 스킬 지속 시간 증가는 합 적용으로 연산합니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
- 블록 점수 1당 1%를 얻습니다.
## 2-6. 스킬 범위 증가 ★
>[!INFO] 스킬 범위 증가 수식
> **실제 스킬 범위 = 스킬 범위 \* (1 + 스킬 범위 증가)**
- 스킬 범위 증가는 합 적용으로 연산합니다.
- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
- 블록 점수 1당 1%를 얻습니다.

- 폐기된 스탯 (`📊 스탯`에서 옮긴 기록): 3-7. 디버프 시간 증가
	- 수식: 실제 디버프 적용 시간 = 디버프 적용 시간 \* (1800 \* X) / (1000 + 7 \* X)
	- 디버프 시간 증가는 수식에 따라 스킬 디버프 시간이 증가합니다.
	- 최대 스탯 값은 500이며, 실제 적용 값은 200% 까지 증가할 수 있습니다.
	- 200 스탯을 가지고 있을 경우 150%가 적용됩니다.
	- 500 스탯을 가지고 있을 경우 200%가 적용됩니다.
	- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
- 폐기된 스탯 (`📊 스탯`에서 옮긴 기록): 3-8. 디버프 중첩
	- 디버프 중첩 스탯은 1당 1씩 중첩되며 최대 4 스탯까지 얻을 수 있습니다.
		- 디버프 중첩 스탯이 0이면, 디버프 최대 중첩은 1이 됩니다. (기본 적용 값)
		- 디버프 중첩 스탯이 1이면, 디버프 최대 중첩은 2가 됩니다.
		- 디버프 중첩 스탯이 4이면, 디버프 최대 중첩은 5가 됩니다.
	- 해당 스탯은 모든 스킬에 적용되지 않고 선택적으로 적용됩니다.
