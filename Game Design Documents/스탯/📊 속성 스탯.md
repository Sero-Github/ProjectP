# 1. 기획 의도
- 속성 효과의 수치와, 속성이 없는 무속성 탄환의 수치를 모아두었습니다. 속성의 정의와 효과 설명은 [[⚡ 속성]]을 따릅니다.
- 속성 효과 수치는 Unity의 `ElementSettings.asset` 한 파일에서 고칩니다. Project 창에서 클릭해 Inspector에서 수정합니다.
# 2. 무속성 탄환
- 공격 스킬을 가방에 배치하기 전에 지속적으로 발사하는 속성 없는 탄환입니다. 동작은 [[⚔️ 스킬#3. 공격 스킬]]을 따릅니다.

| 스탯            | 기획 값 | 조절 위치                                    |
| ------------- | ---- | ---------------------------------------- |
| 재사용 대기 시간 (초) | 미정   | `Bullet_Basic.asset` · `cooldown`        |
| 이동 속도         | 미정   | `Bullet_Basic.asset` · `moveSpeed`       |
| 동시 발사 개수      | 미정   | `Bullet_Basic.asset` · `projectileCount` |
| 관통력           | 미정   | `Bullet_Basic.asset` · `pierce`          |
| 공격력           | 미정   | `Bullet_Basic.asset` · `attack`          |

> [!QUESTION] 확인 필요
> 무속성 탄환은 기획 값이 없지만 에셋에는 값이 들어 있습니다. 기획 값을 정해야 합니다. ([[스탯 문서 분리 계획#6. 기획 값과 현재 에셋 값의 차이]] 7번)

# 3. 공유 스탯
| 스탯                | 기획 값           | 조절 위치                                    |
| ----------------- | -------------- | ---------------------------------------- |
| 지속 대미지 간격 (감전, 독) | 1초             | `ElementSettings.asset` · `tickInterval` |
| 수치 계산 기준          | 속성 대미지 100당 증가 | 코드 상수 `ElementSettings.AttackUnit`       |

# 4. 개별 스탯
## 4-1. 빨강(폭발)
| 스탯     | 기획 값       | 조절 위치                                       |
| ------ | ---------- | ------------------------------------------- |
| 스탯 대미지 | 속성 대미지와 같음 | 코드                                          |
| 폭발 대미지 |            |                                             |
| 폭발 범위  | 미정         | `ElementSettings.asset` · `explosionRadius` |
## 4-2. 주황(강화)
| 스탯                | 기획 값                       | 조절 위치                                                 |
| ----------------- | -------------------------- | ----------------------------------------------------- |
| 스탯 대미지            | 현재 주입된 속성 대미지 + 주황 속성의 대미지 | 코드                                                    |
| 노랑·초록·파랑 효과 추가 중첩 | 최대 한 번                     | `ElementSettings.asset` · `orangeExtraStacks`         |
| 보라 독 중첩           | 최대 다섯 번                    | [[#4-6. 보라(독)]]의 최대 중첩 수와 같음                          |
| 회색 넉백 배율          | 1.5배                       | `ElementSettings.asset` · `orangeKnockbackMultiplier` |

## 4-3. 노랑(감전)
| 스탯           | 기획 값            | 조절 위치                                          |
| ------------ | --------------- | ---------------------------------------------- |
| 스탯 대미지       | 90%             |                                                |
| 감전 대미지       | 1초마다 속성 대미지의 5% | `ElementSettings.asset` · `shockDamagePercent` |
| 공격 속도 둔화 기본값 | 5%              | `ElementSettings.asset` · `attackSlowBase`     |
| 공격 속도 둔화 증가량 | 속성 대미지 100당 5%  | `ElementSettings.asset` · `attackSlowPer100`   |
| 공격 속도 둔화 최대치 | 40%             | `ElementSettings.asset` · `attackSlowMax`      |
- 예시: 속성 대미지 150을 가진 경우 10% 느려져야 합니다.

## 4-4. 초록(둔화)
| 스탯           | 기획 값           | 조절 위치                                      |
| ------------ | -------------- | ------------------------------------------ |
| 이동 속도 둔화 기본값 | 10%            | `ElementSettings.asset` · `moveSlowBase`   |
| 이동 속도 둔화 증가량 | 속성 대미지 100당 5% | `ElementSettings.asset` · `moveSlowPer100` |
| 이동 속도 둔화 최대치 | 40%            | `ElementSettings.asset` · `moveSlowMax`    |
- 예시: 속성 대미지를 150을 가진 경우 15%가 느려져야 합니다.

## 4-5. 파랑(방어력 감소)
| 스탯             | 기획 값            | 조절 위치                                              |
| -------------- | --------------- | -------------------------------------------------- |
| 방어력 감소 기본값     | 10%             | `ElementSettings.asset` · `defenseReductionBase`   |
| 방어력 감소 증가량     | 속성 대미지 100당 10% | `ElementSettings.asset` · `defenseReductionPer100` |
| 방어력 감소 최대치     | 100%            | `ElementSettings.asset` · `defenseReductionMax`    |
| 속성을 잃은 뒤 유지 시간 | 5초              | `ElementSettings.asset` · `defenseReductionLinger` |

## 4-6. 보라(독)
| 스탯      | 기획 값             | 조절 위치                                           |
| ------- | ---------------- | ----------------------------------------------- |
| 독 대미지   | 1초마다 속성 대미지의 10% | `ElementSettings.asset` · `poisonDamagePercent` |
| 최대 중첩 수 | 5회               | `ElementSettings.asset` · `poisonMaxStacks`     |

## 4-7. 회색(넉백)
| 스탯    | 기획 값                | 조절 위치                                                   |
| ----- | ------------------- | ------------------------------------------------------- |
| 넉백 거리 | 1초간 이동할 수 있는 거리의 3배 | `ElementSettings.asset` · `knockbackDistanceMultiplier` |
| 넉백 시간 | 미정                  | `ElementSettings.asset` · `knockbackDuration`           |

> [!QUESTION] 확인 필요
> 넉백 시간은 기획 값이 없지만 에셋에는 값이 들어 있습니다. ([[스탯 문서 분리 계획#6. 기획 값과 현재 에셋 값의 차이]] 14번)
