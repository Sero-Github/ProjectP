# 1. 기획 의도
- 몬스터의 수치를 한곳에서 확인하고 조절하기 위한 문서입니다. 몬스터의 동작은 [[👿 몬스터]]를 따릅니다.
- 현재 모든 스탯은 임시입니다. 추후 스테이지 별, 라운드 별 배율을 가질 수 있습니다.
- 표의 "조절 위치"는 Unity에서 값을 고치는 곳입니다. `.asset` 파일은 Project 창에서 클릭해 Inspector에서 고치고, "코드"는 코드를 고쳐야 합니다.
# 2. 공유 스탯
- 모든 몬스터 종류에 같은 규칙으로 적용되는 스탯입니다.

| 스탯                    | 기획 값                                                      | 조절 위치                                                     |
| --------------------- | --------------------------------------------------------- | --------------------------------------------------------- |
| 스탯 계산                 | 배율과 현재 라운드 수치에 따라 계산                                      | 코드 (`EnemyData`)                                          |
| 레벨(라운드 수치)            | 1스테이지 10라운드 → 10, 2스테이지 1라운드 → 11 (1스테이지 별로 10라운드가 있을 경우) | 스테이지당 라운드 수: 코드 상수 `StageTable.RoundsPerStage`            |
| 소수점 처리                | 버림                                                        | 코드                                                        |
| 근접 공격 쿨타임 (초)         | 미정 (쿨타임이 적용된다고만 되어 있음)                                    | `EnemyData 1~4.asset` · `contactInterval`                 |
| 오각형 최대 등장 수           | 한 스테이지에 5개 (디자인 방향성 제한)                                   | `EnemySpawnSettings.asset` · Pentagon · `maxPerStage`     |
| 라운드 생성 시간 (초)         | 100                                                       | `RoundSettings.asset` · `roundDuration`                   |
| 사망 파티클 지속 시간 (초)      | 1                                                         | `EnemyDeathParticles` 컴포넌트 · `lifetime`                   |
| 생성 위치 (화면 가장자리 바깥 거리) | 미정 ("화면 밖 랜덤 위치"만 있음)                                     | `EnemySpawnSettings.asset` · `spawnMargin`                |
| 블록 드롭 확률              | 미정                                                        | `BlockDropper` 컴포넌트 · `dropChance` ([[🧱 블록#5-2. 드롭 확률]]) |

> [!QUESTION] 확인 필요
> 코드의 스탯 계산식은 `고정 값 + 배율 × 레벨`입니다. 이 식을 기획 값으로 확정할지 확인이 필요합니다. ([[스탯 문서 분리 계획#6. 기획 값과 현재 에셋 값의 차이]])

> [!QUESTION] 확인 필요
> 라운드 생성 시간은 기획 값(100초)과 에셋 값이 다르고, 근접 공격 쿨타임은 기획 값이 없습니다. ([[스탯 문서 분리 계획#6. 기획 값과 현재 에셋 값의 차이]] 1번, 12번)

# 3. 몬스터 공통 스탯
- 조절 위치: 원형 `EnemyData 1.asset`, 삼각형 `EnemyData 2.asset`, 사각형 `EnemyData 3.asset`, 오각형 `EnemyData 4.asset`

| 스탯     | 원형   | 삼각형          | 사각형    | 오각형       | 필드                  |
| ------ | ---- | ------------ | ------ | --------- | ------------------- |
| 유형     | 기본 적 | 변칙 이동형       | 탱커, 버퍼 | 중간 보스, 보스 | –                   |
| 공격 방식  | 근접   | 근접           | 근접     | 근접        | –                   |
| 이동 방식  | 직선   | 직선 + 간헐적 대각선 | 직선     | 미정        | –                   |
| 고정 HP  | –    | 1.0          | 1.0    | 20.0      | `baseHp`            |
| HP 배율  | 1.2  | 1.0          | 3.0    | 5.0       | `hpMultiplier`      |
| 고정 공격력 | –    | 1            | 1      | 1         | `baseAttack`        |
| 공격력 배율 | 1.0  | 1.2          | 0.8    | 2.1       | `attackMultiplier`  |
| 고정 방어력 | 0    | 0            | 3.0    | 10.0      | `baseDefense`       |
| 방어력 배율 | 1.5  | 1.0          | 2.0    | 5.0       | `defenseMultiplier` |
| 이동 속도  | 1.2  | 1.0          | 0.6    | 0.2       | `moveSpeed`         |
- "–"는 기획 표에 해당 항목이 없음을 뜻합니다.
# 4. 몬스터 고유 스탯
- 해당 스탯은 각 몬스터에 따라 적용되는 고유한 스탯입니다.
## 4-1. 삼각형

| 스탯        | 수치                 | 필드                 |
| --------- | ------------------ | ------------------ |
| 대각선 이동 주기 | 5.0                | `coolMovement`     |
| 대각선 이동 거리 | 1000% (이동 속도에 비례한) | `distanceMovement` |
## 4-2. 사각형
- 버프의 지속 시간이 없고, 버프 반경에서 벗어나면 버프는 사라집니다.
- 사각형 적이 생성될 때 버프 유형은 랜덤으로 설정됩니다.

| 스탯         | 수치                         | 필드                        |
| ---------- | -------------------------- | ------------------------- |
| 버프 유형      | 1 : 이동 속도 증가<br>2 : 방어력 증가 | `buffType`                |
| 버프 반경      | 100                        | `buffDistance`            |
| 이동속도 버프 배율 | 1.5                        | `buffMoveSpeedMultiplier` |
| 방어력 증가 배율  | 1.2                        | `buffDefenceMultiplier`   |
> [!QUESTION] 확인 필요
> 원형의 고정 HP·고정 공격력, 모든 유형의 방어력은 기획 값이 없지만 에셋에는 필드가 있습니다. 오각형 에셋에는 기획에서 삭제된 골드 값(`baseGold`, `goldMultiplier`)이 남아 있습니다. ([[스탯 문서 분리 계획#6. 기획 값과 현재 에셋 값의 차이]] 8~10번)
